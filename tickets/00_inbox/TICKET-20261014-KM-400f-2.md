## Acceptance Criteria

```gherkin
Given the declared retention bound is at most 3 retained generations and a minimum retirement age of 24 hours
And the repository holds active generation G32 and 26 older retained generations
And an unexpired pinned continuation is held against G28
And a second repository in the same database holds its own 4 generations
When generation G33 is published successfully for the first repository
Then G33 becomes the active generation and G32 is retired, and both remain intact and readable
And every generation of the first repository outside the declared bound is reclaimed within the same publication operation
And G28 is not reclaimed while its continuation is unexpired
And the second repository's 4 generations are unchanged in count, canonical identity and content
And the publication result reports the count of generations reclaimed and the count retained
And the result names each retained generation together with the reason it was retained

Given the first publication after G28's pinned continuation has expired
When that publication succeeds
Then G28 is reclaimed in that same operation
And its continuation receives an explicit expiration result rather than a missing-data result

Given a repository whose generations are all inside the declared bound
When a new generation is published successfully
Then the publication reports a reclaimed count of zero
And it reports that figure explicitly rather than omitting it

Given publication of G33 fails before the active pointer is switched
When the operation returns
Then no generation of either repository is reclaimed
And G32 remains the active generation
And the failure result reports a reclaimed count of zero
```
