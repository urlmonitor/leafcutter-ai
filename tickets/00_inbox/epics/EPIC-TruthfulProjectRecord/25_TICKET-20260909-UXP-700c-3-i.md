## Acceptance Criteria

```gherkin
Given the same project record and the same automatic check,
When the check runs on Windows and again on a POSIX system,
Then both runs report the same verdict and name the same artifacts,
And a difference that consists only of how the two systems spell a path is never reported as
  the record having fallen behind,
And the keys the record's index uses to name its own files are spelled identically on both
  systems, so a rebuild produced on one is byte-identical to a rebuild produced on the other.
```

- [ ] AC-1: both runs report the same verdict and name the same artifacts
- [ ] AC-2: a difference that consists only of how the two systems spell a path is never reported as
- [ ] AC-3: the keys the record's index uses to name its own files are spelled identically on both
