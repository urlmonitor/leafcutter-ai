## Acceptance Criteria

```gherkin
Given an AC whose implemented_by list already contains an entry pointing at the
  ticket produced by a prior generation of that same AC,
When a ticket is generated again from that AC by the generator's back-reference
  writer (regeneration of the same AC's ticket),
Then after the back-reference is written the AC's implemented_by list contains
  exactly one entry for that ticket (the prior same-ticket entry is replaced or
  deduplicated, not appended a second time),
And repeated regenerations of the same AC do not grow the implemented_by list
  (the back-reference write is idempotent for the same ticket).
```
