## Acceptance Criteria

```gherkin
Given a leaf AC whose it_requirements is in structured form and names a source
  file as its edit surface (for example reference_file_path:
  "scripts/ac_store/generate_ticket_from_ac.py"),
And whose doc_links names a documentation path
  (for example "docs/reference/ac-schema.md"),
When a ticket is generated from that AC by generate_ticket_from_ac.py,
Then the generated ticket's files_touched list contains
  "scripts/ac_store/generate_ticket_from_ac.py" (the source edit surface named
  by it_requirements),
And the generated ticket's files_touched list also contains
  "docs/reference/ac-schema.md" (the doc_links path),
And files_touched is the de-duplicated union of the it_requirements edit
  surface(s) and the doc_links paths: a path named in both it_requirements and
  doc_links appears exactly once in files_touched.

Given a leaf AC whose it_requirements names a source file that is identical to
  a path also listed in doc_links,
When a ticket is generated from that AC,
Then that path appears exactly once in files_touched (no duplicate entry).
```
