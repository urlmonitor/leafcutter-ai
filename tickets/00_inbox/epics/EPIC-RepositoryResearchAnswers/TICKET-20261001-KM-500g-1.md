## Implementation Notes

```yaml
- Preserve immutable source provenance, bounded registered read-only queries and existing
  authorization, budgets and retries. No arbitrary Cypher, new network endpoint, source-write
  permission, independent telemetry store or automatic activation is added.
- Use the existing observation owner and tracer lifecycle for standalone composition.
  Execution outcome and original-question fulfillment are separate fields derived
  from actual requirements/evidence; query success or a span cannot satisfy a missing
  field.
- Correlate repository, source SHA/generation/query and evidence IDs from the same
  request/attempt. Absent provenance stays unknown; redact credentials and unrestricted
  source contents under existing privacy rules.
- Emit final fulfillment, missing required fields and completeness limits after final
  assessment and before observation completion and bounded flush/shutdown. A pre-assessment
  retrieval span alone is insufficient for the final outcome.
- Return delivery state separately from a locally allocated trace ID. Claim an accessible
  Langfuse reference only after authorized matching remote observation is established;
  otherwise return available correlation plus explicit unverified/untraced state without
  promising ingestion.
- Actual remote verification is separately opt-in under existing provider/data-transfer
  permissions. Offline exporter checks prove serialization and correlation only; no
  new replay loop or telemetry stack is authorized.
```
