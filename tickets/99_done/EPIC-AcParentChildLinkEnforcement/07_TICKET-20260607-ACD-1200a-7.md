## Acceptance Criteria

```gherkin
Given goal_to_epic.py has generated tickets for all leaf ACs beneath a goal,
When the system assembles the EPIC folder,
Then it also writes a Master_Plan.md at the root of the epic folder,
And Master_Plan.md contains:
  - A one-paragraph summary of the goal AC's criteria (the "why"),
  - The ordered list of tickets with their titles and source AC IDs,
  - The dependency graph between tickets (derived from AC depends_on),
  - The component(s) involved,
  - The assigned agents across all tickets,
And the file follows the same structure as Master_Plan.md files produced
  by the create-epic agent (frontmatter with epic_name, created, status,
  followed by ## Goal, ## Tickets, ## Dependencies sections),
And /build-feature can read this file to understand epic-level context
  without requiring human authoring.
```
