# One door: the finished state is only ever written by the mechanism that checks it, and the blanket override is not the way through

## Actor / Goal

As the leafcutter-ai system, I want to implement AC `BO-400e-3` — One door: the finished state is only ever written by the mechanism that checks it, and the blanket override is not the way through — so that the acceptance criterion is satisfied.

## Context

This ticket was generated from AC store entry `BO-400e-3`. Component: `build-orchestration`. Assigned agent: `python-coder`. Estimated complexity: `L`. Complexity: `high`.

## Acceptance Criteria

```gherkin
Given a ticket that a drive is about to close,
  And two routes by which its recorded state could today be set to finished -- the
    mechanism that reads the ticket's record and checks it, and a direct edit of that
    record by whoever was asked to close the ticket,
When the drive closes the ticket,
Then the ticket's record is written to the finished state by the checking mechanism and
  by nothing else,
  And the instruction under which the close is carried out names that mechanism as the
    route and does not describe editing the recorded state directly,
  And the close is carried out without the blanket override -- the one that switches off
    the allowed-transition rules along with the check -- so a close that only succeeds
    because the override was passed is not a close through this door,
And given the same ticket and a run in which the checking mechanism refuses,
When the drive reaches the close,
Then no finished state appears on that ticket by any route: the recorded state is
  unchanged, and the run reports the ticket as not closed rather than closing it another
  way,
And given the same ticket carried instead by the driver that carries a single ticket
  rather than a whole epic,
When that driver closes it,
Then the close goes through the same mechanism and produces the same recorded state,
So there is exactly one way the finished state is ever reached, and the route that
  bypasses the check is closed rather than discouraged.
```
