description: "Register entries plus one generated-file refresh. No production code. A /fast-lane-build run against INF-400c-2-ii was monitored end to end; the lane resolved its build set correctly, produced a genuinely red baseline (a real AttributeError on a field that did not exist yet, reproduced by hand rather than taken from the gate's own report), turned it green, and halted at review on a legitimate finding — that halt is the gate working and is not recorded as a defect. Two real defects surfaced around it. KI-BO-029 records that the fast lane stages with git add -A into a worktree its own bootstrap already dirtied: setup_ticket_worktree.py runs build.py, which regenerates docs/agents/cards/*.card.md, so the tree is dirty before any agent runs and the churn lands in the PR. Reproduced on three independent worktrees. The add -A is deliberate — the Changelog phase depends on it to get its entry into the diff — so the entry records that the fix is a computed stage set rather than a narrower sweep, plus the cheaper alternative of leaving bootstrap clean. The entry also records a second, independent path to the same outcome that this very commit hit: the transform-doc-index pre-commit hook regenerates docs/INDEX.md and adds it mid-commit, and because docs/INDEX.md is not in check_changelog_presence.py's EXEMPT_PREFIXES, a PR consisting solely of exempt known-issues edits was failed by the required Changelog entry present gate naming a file the author never touched. That mechanism affects every commit touching docs, not only fast-lane ones. KI-CG-016 records that enforce_commit_delegation matches the phrase anywhere in the command string, so read-only commands are refused — grep -c 'git commit' CLAUDE.md is blocked, as was the grep auditing the lane's staging behaviour, which is the work that produced KI-BO-029. Filed low because it is loud and trivially worked around, but noted because it disproportionately obstructs the reviews most likely to find the guardrail's own defects; the converse question of whether a substring matcher is also under-inclusive is flagged for the owner and deliberately not probed, since testing a safety hook for evasions is not an appropriate way to characterise it. KI-BP-015 goes from one occurrence to three rather than being duplicated, per the register's own rule, with a note that KI-BO-029 raises the ceiling on its low rating because drift repaired at random intervals by PRs that never mention it is harder to reason about than steady staleness. Finally docs/INDEX.md gains the ADR-035 row it was missing: that ADR is on main but was never indexed, so the regeneration is a real content fix rather than pure churn, alongside one description-field rewrite for an unrelated how-to that is churn."
