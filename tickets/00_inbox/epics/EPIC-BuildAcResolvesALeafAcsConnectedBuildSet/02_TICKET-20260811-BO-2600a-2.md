## Acceptance Criteria

```gherkin
Given the select_connected subcommand of scripts/build_orchestration/fast_lane.py,
And a new --exclude-structural-parent flag on that subcommand,
When select_connected is invoked with --exclude-structural-parent --ac <id> --ac-root <root>,
Then it calls resolve_connected_build_set with exclude_structural_parent=True and
  prints the resulting ordered id list as JSON,
And when the flag is omitted the subcommand behaves exactly as it does today
  (exclude_structural_parent defaults to False),
And a missing AC id still exits non-zero with the existing ValueError-derived message.
```

- [ ] AC-3: when the flag is omitted the subcommand behaves exactly as it does today
- [ ] AC-4: a missing AC id still exits non-zero with the existing ValueError-derived message.
