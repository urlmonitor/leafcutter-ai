# 01: Create .github/ISSUE_TEMPLATE/config.yml on leafcutter-ai

## Goal

In order to prevent blank, unstructured issues and route general questions to Discussions, we need a `config.yml` that disables blank issues and provides a contact link to GitHub Discussions.

## Context

Stub generated by create-epic. Harden with create-ticket (depth 3).

This file is the gatekeeper for the entire ISSUE_TEMPLATE suite. Without it, GitHub renders a "New Issue" button that lets users submit empty freeform issues. Setting `blank_issues_enabled: false` forces users through the structured templates (tickets 02–04).

All changes are on the `urlmonitor/leafcutter-ai` upstream repo. This ticket has no `depends_on` — it can be executed as soon as `EPIC-LeafcutterMVP ST-3` publishes the repo.

## Acceptance Criteria

```gherkin
Given leafcutter-ai is published on GitHub
When a user clicks "New Issue" on the leafcutter-ai repo
Then they see only the structured templates (bug, feature, compat) — no blank option
And there is a contact link pointing to GitHub Discussions for general questions
And config.yml has blank_issues_enabled: false
```
