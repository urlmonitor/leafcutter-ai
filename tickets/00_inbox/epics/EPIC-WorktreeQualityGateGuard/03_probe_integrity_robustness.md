## Implementation Tasks

### python-coder
- [ ] Add required-hook-ID validation to Check C (git_hook check)
  - Assert that the pre-commit hook is named exactly pre-commit (not pre-commit-backup, etc.)
  - Validate hook shebang and path
  - Anti-spoof: reject hooks that are symlinks to non-upstream targets
- [ ] Implement multi-stage detection in Check D (canary check)
  - Verify canary is registered in exactly one stage: [manual]
  - Assert canary does not appear in any other stage
  - Fail if canary is missing from config or moved to non-manual stage
- [ ] Add freshness/drift detection
  - Compare hook mtime against config mtime
  - Warn if hook is stale relative to config
  - Fail if hook is missing but config is present
- [ ] Implement timeout enforcement
  - Set subprocess timeout to 10 seconds for Check D invocation
  - Catch TimeoutExpired and treat as Check D failure
  - Return structured timeout error in stderr
- [ ] Handle hooksPath edge cases
  - Support custom hooksPath in .git/config (non-standard locations)
  - Resolve relative hooksPath paths correctly
  - Fail gracefully if hooksPath is unreadable

- [ ] Add multi-stage validation tests

- [ ] Add freshness/drift tests
