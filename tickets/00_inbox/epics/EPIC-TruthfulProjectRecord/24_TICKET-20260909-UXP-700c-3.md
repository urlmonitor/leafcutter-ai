# The record's checker runs by itself, at the moment the record or the code it describes changes

## Actor / Goal

As the leafcutter-ai system, I want to implement AC `UXP-700c-3` — The record's checker runs by itself, at the moment the record or the code it describes changes — so that the acceptance criterion is satisfied.

## Context

## Acceptance Criteria

```gherkin
Given a change that touches either the project record or a file the record points at,
When that change is offered to the project's automatic checks,
Then the record's checker runs as one of them,
And the verdict the record's checker reaches is the verdict those checks report for the
  record,
And a change that touches neither the record nor anything the record points at does not run
  the record's checker.
```

- [x] AC-1: the record's checker runs as one of them
- [x] AC-2: the verdict the record's checker reaches is the verdict those checks report for the
- [x] AC-3: a change that touches neither the record nor anything the record points at does not run
