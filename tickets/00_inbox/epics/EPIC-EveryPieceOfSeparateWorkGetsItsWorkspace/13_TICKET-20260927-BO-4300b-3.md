# When more than one project could be meant, the request is refused and names them

## Actor / Goal

As the leafcutter-ai system, I want to implement AC `BO-4300b-3` — When more than one project could be meant, the request is refused and names them — so that the acceptance criterion is satisfied.

## Context

## Acceptance Criteria

```gherkin
Given a folder that is not a project and contains two projects, "shop" and
  "blog",
When a workspace is requested from that folder without saying which project,
Then the request is refused,
And the refusal names both "shop" and "blog" as the candidates it could not
  choose between,
And no workspace and no line of work is created in either project,
And given the same request names "shop" as its project, it is answered ready
  with a workspace that is a copy of shop.
```

- [ ] AC-1: the request is refused
- [ ] AC-2: the refusal names both "shop" and "blog" as the candidates it could not
- [ ] AC-3: no workspace and no line of work is created in either project
- [ ] AC-4: given the same request names "shop" as its project, it is answered ready
