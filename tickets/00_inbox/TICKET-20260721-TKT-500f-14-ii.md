## Acceptance Criteria

```gherkin
This edge case refines the recognised-source-code extension set that
TKT-500f-14 uses to decide the code-ticket gate signal, so the set neither
over-includes non-code files nor omits common compiled/module source.

Given a leaf AC whose generated ticket's files_touched contains only markup,
  style, or shell files (.html, .css, .sh) and is assigned to a non-coder agent,
When a ticket is generated from that AC by generate_ticket_from_ac.py,
Then those extensions are NOT classified as gating source code — .html/.css/.sh
  alone do not force-add ac-validator and ac-fulfillment-gate to the agents map.

Given a leaf AC whose generated ticket's files_touched contains a common
  non-Python source file (.go, .rs, or .mjs),
When a ticket is generated from that AC,
Then that extension IS recognised as gating source code — ac-validator and
  ac-fulfillment-gate are wired as needed phases, the same way a .py or .js
  source file already triggers the gate under TKT-500f-14.
```
