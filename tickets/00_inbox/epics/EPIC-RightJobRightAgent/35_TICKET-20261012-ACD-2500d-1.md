## Actor / Goal

## Acceptance Criteria

```gherkin
Given a requirement whose criteria change the retry cap applied when a build step fails,
  and whose declared files are (a) the runbook in which that cap is defined and (b) a
  reference document that only describes the cap,
When the file-aware step runs on it,
Then it reports (a) as consistent with the requirement's intent,
And it reports (b) as "describes, does not implement", naming the file and the line range
  it read,
And it reports a declared file that is absent from the repository and not marked
  to-be-created, naming its path,
And its report names every file it opened.
```

- [ ] AC-4: it reports a declared file that is absent from the repository and not marked
- [ ] AC-5: its report names every file it opened.
