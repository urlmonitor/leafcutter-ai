# A sequence diagram shows every point where the route stops to ask and what follows from each answer

## Actor / Goal

As the leafcutter-ai system, I want to implement AC `ACD-2100e-1` — A sequence diagram shows every point where the route stops to ask and what follows from each answer — so that the acceptance criterion is satisfied.

## Context

This ticket was generated from AC store entry `ACD-2100e-1`. Component: `ac-driven-dev`. Assigned agent: `architecture-diagram-author`. Estimated complexity: `M`. Complexity: `medium`.

## Acceptance Criteria

```gherkin
Given a reader who wants to know where the route stops to ask for a decision and
  what follows from each answer,
When they open the project's architecture diagrams,
Then a sequence diagram depicts each point at which the route asks for a
  decision -- approving a drafted product-truth artifact; approving the
  mid-pipeline authoring stage; giving final approval; choosing how to proceed
  when the request looks already covered; and deciding what to do with stranded
  drafts from an earlier run -- and depicts no decision point the route does not
  present,
And each of them is shown as a question put to the person running the route with
  no exchange in which an agent supplies the answer,
And each of them is shown with all three of its exits: an answer from the person
  and the run continuing; no person reachable and the run waiting on a record
  that outlives the process; and an answer that cannot be attributed to the
  person refused with the run still waiting,
And exactly one path in the diagram ends in the drafted work being discarded and
  it is the path the person chooses,
And each path depicted names the criterion whose delivered behaviour it depicts,
And the diagram is reachable from the documentation index and declares the same
  component as this criterion.
```
