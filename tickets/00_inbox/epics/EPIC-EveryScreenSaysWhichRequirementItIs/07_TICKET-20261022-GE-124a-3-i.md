## Implementation Notes

```yaml
- THE RULE IS RE-EXPORT-ONLY, NOT FILENAME. A file named index.tsx that renders markup
  is IN scope; a file named anything at all whose every non-comment, non-import statement
  is a re-export is out. Keying on the filename `index` is the shortcut that exempts
  a real page component that happens to be a route index.
- The recorded reason must be the enumerated code 're-export-only' — distinct from
  'no-markup' and from 'extension-not-in-scope'. The three collapse trivially in an
  implementation that returns a bare boolean, and the PO's clustered-opt-out review
  cannot tell them apart afterwards.
- Do not treat an uppercase identifier in an export statement as evidence of a component.
  `export { CoverageExplorer }` is component-shaped to a naive scan and is exactly
  the false positive this AC pins; the deciding property is markup, and a barrel contains
  none.
```
