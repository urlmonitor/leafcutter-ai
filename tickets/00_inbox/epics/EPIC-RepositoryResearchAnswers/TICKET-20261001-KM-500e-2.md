## Implementation Notes

```yaml
- Retain immutable repository/source SHA provenance, bounded registered read-only
  queries and existing kernel authorization, budgets and retries. This contract adds
  no arbitrary Cypher, new network endpoint, source-write permission or automatic
  query activation.
- The named fields below describe the planned observable semantic contract; preserve
  compatible existing envelope fields and version any incompatible extension. Required
  unavailable values stay explicit and are never inferred from an evaluation oracle.
- Carry canonical field names and their availability separately through projection
  and disclosure. Existing generations lacking a newly required field remain incompatible
  for that answer unless republished; do not silently fill from an unrelated workspace
  or lifecycle status.
- An exact criterion answer includes the complete requested canonical clause at its
  pinned source locator. Truncation or byte budgets must mark the clause incomplete
  and prevent an exact-complete claim; the source oracle is assessment-only.
- Preserve distinct graph lifecycle status, requirement status, work status and readiness
  even where literal values coincide. Absence in canonical source, absence in projection
  and withheld disclosure require attributable diagnostics; otherwise classify availability
  as unknown.
- Similarity or duplicate/conflict interpretation cites the exact compared clauses
  and is labeled inference. It cannot rewrite canonical requirements or silently select
  one as authoritative.
```
