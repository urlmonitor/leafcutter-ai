## Acceptance Criteria

```gherkin
Given resolve_connected_build_set in scripts/build_orchestration/fast_lane.py,
And a new keyword-only parameter exclude_structural_parent that defaults to False,
When the transitive depends_on closure is walked for a node,
Then with exclude_structural_parent=True any dependency equal to
  derive_parent_id(node) (from scripts/ac_store/ac_parent_id.py) is skipped and
  NOT expanded into the build set,
And genuine (non-structural-parent) dependencies are still walked and included,
And the node's own descendants still enter the set via the subtree union
  (so excluding the structural parent never drops the AC's real children),
And with the default exclude_structural_parent=False the function behaves
  byte-identically to today (every depends_on entry walked) — preserving all
  existing fast-lane callers.
```
