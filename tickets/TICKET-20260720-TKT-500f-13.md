## Actor / Goal

## Acceptance Criteria

```gherkin
Given a leaf AC whose component belongs to a namespace where the components.json
  graph id differs from the index.yaml kebab namespace key (for example graph id
  build_orchestration versus namespace build-orchestration),
When a ticket is generated from that AC by generate_ticket_from_ac.py,
Then the generated ticket's components LIST contains the underscore
  components.json graph id (build_orchestration) so the ticket passes the
  Component-vocab CI check,
And when the generated ticket also emits a scalar component field, that scalar
  still carries the index.yaml kebab namespace key (build-orchestration)
  unchanged,
And only the components LIST is normalized to the graph vocabulary — the
  two-axis taxonomy (kebab namespace scalar, underscore graph-id list) is
  preserved rather than the kebab value being copied into the LIST.
```
