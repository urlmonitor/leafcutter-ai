# A registry whose contents cannot be understood is reported as unusable and not as a permission verdict

## Actor / Goal

## Context

## Acceptance Criteria

```gherkin
Given a run in which the agent registry exists and can be opened and read but
  its contents cannot be interpreted as a registry -- for example the file is
  truncated part-way through,
When the startup check runs,
Then the run stops and reports that the registry was read but could not be
  interpreted,
And that report differs in wording from the report given when the registry
  cannot be read at all,
And the report contains no statement about whether any agent is permitted to run
  repository commands,
And the report states where in the contents interpretation failed.
```

- [ ] AC-1: the run stops and reports that the registry was read but could not be
- [ ] AC-2: that report differs in wording from the report given when the registry
- [ ] AC-3: the report contains no statement about whether any agent is permitted to run
- [ ] AC-4: the report states where in the contents interpretation failed.

## Implementation Notes

```yaml
- The change must land under templates/. The deployed workflow is build output.
- 'Fail closed: the run still stops. See ACD-2100b-4.'
- The four outcome reports must be distinguishable by their observable output alone.
  A shared catch-all message satisfies each outcome's own record read in isolation
  and leaves the operator unable to tell a wrong location from a corrupt file.
- The report must locate the failure within the contents -- an offset, a line, or
  the fragment at which interpretation stopped. 'Could not interpret the registry'
  without a position sends the operator to read the whole file by eye.
- The report must not name a permission setting and must not assert anything about
  any agent's permission.
- 'Must satisfy the repository error-handling policy: the interpretation failure must
  be caught by type and logged at WARNING or higher before the halt -- it must not
  propagate as an unhandled failure, which stops the run for a reason the operator
  cannot read.'
- Must not emit the registry's contents into the report beyond the fragment needed
  to locate the failure -- the file can carry project configuration.
```
