# Fix _dfs_collect_leaves to use level-based leaf detection

## Summary

`_dfs_collect_leaves()` in `scripts/ac_store/scan_ac_store.py` (lines 489-515) uses
`covered_by == []` as its sole leaf signal. But the module already defines
`_LEAF_LEVELS = frozenset({"L2", "L3"})` at line 46, used correctly by `_is_leaf()`
and by `build_ac_mode_detection.py`.

The tree-traversal function ignores the level field and treats any AC with non-empty
`covered_by` as a composite pass-through. This means an L2 AC that has L3 edge-case
children is never emitted as a leaf — only its L3 children are.

## Root Cause

`_dfs_collect_leaves()` line 508: `if not children:` — only emits the node when
`covered_by` is empty. Should instead check `level in _LEAF_LEVELS`.

## Fix

Change `_dfs_collect_leaves()` to:
1. If the node's level is in `_LEAF_LEVELS` (L2/L3): emit it as a leaf AND recurse into its `covered_by` children (so L3 edge cases are also collected).
2. If the node's level is L0/L1: recurse only (pure pass-through composite).
3. If the node has no `covered_by` children and is NOT in `_LEAF_LEVELS`: emit as leaf (backward compat for any edge case).

## Acceptance Criteria

Given the AC store contains:
  - ROOT-001 (L0, covered_by: [ROOT-001a])
  - ROOT-001a (L1, covered_by: [ROOT-001a-1, ROOT-001a-2])
    - ROOT-001a-1 (L2, covered_by: [])
    - ROOT-001a-2 (L2, covered_by: [ROOT-001a-2-i])
      - ROOT-001a-2-i (L3, covered_by: [])

When `traverse_ac_tree("ROOT-001", ac_store_root)` is called,
Then the result is `["ROOT-001a-1", "ROOT-001a-2", "ROOT-001a-2-i"]`.

L2/L3 nodes are always leaves. L0/L1 nodes are always composites.
