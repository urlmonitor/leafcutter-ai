## Acceptance Criteria

```gherkin
Given the /create-ac workflow creates a commit after a stage approval,
When the commit is recorded in git history,
Then the commit message first line contains: the text "create-ac",
  the stage name (one of "PO", "BA", or "IT-PO"), and the target component name,
And the commit message body lists every AC ID included in the commit
  (e.g. "ACD-300g, ACD-300g-1, ACD-300g-2"),
And the commit message body states whether this is a mid-pipeline commit
  or the final commit of the run,
And a reviewer reading only the git log can determine which /create-ac stage
  produced each committed AC file without opening the files.
```
