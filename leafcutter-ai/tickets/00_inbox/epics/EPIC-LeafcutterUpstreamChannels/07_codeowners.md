# 07: Create CODEOWNERS on leafcutter-ai

## Goal

In order to ensure every PR against `leafcutter-ai` automatically requests a review from the maintainer, we need a `CODEOWNERS` file that maps `@urlmonitor` as the default reviewer for all paths.

## Context

Stub generated by create-epic. Harden with create-ticket (depth 3).

All changes are on the `urlmonitor/leafcutter-ai` upstream repo. This ticket can run in parallel with 01–06, 08.

The CODEOWNERS file should contain a single rule: `* @urlmonitor`. This ensures GitHub auto-requests a review from `@urlmonitor` on every PR. If the maintainer's GitHub handle differs from `urlmonitor`, verify before merging.

The CODEOWNERS file should be placed at the repo root (not `.github/CODEOWNERS`) unless there is a reason to place it under `.github/`.

## Acceptance Criteria

```gherkin
Given leafcutter-ai is published on GitHub with branch protection on main
When a contributor opens a PR against leafcutter-ai main
Then GitHub automatically requests a review from @urlmonitor (or the verified maintainer handle)
And CODEOWNERS contains "* @urlmonitor" (or the verified handle)
```
