  compatible existing envelope fields and version any incompatible extension. Required
  unavailable values stay explicit and are never inferred from an evaluation oracle.

  does not add universal code indexing, call-graph extraction or a new source-inspection
  permission.

  attributable inspected content and revision; explanations distinguish inspected
  source facts from inference and unknown stages.

  or dependency does not exist.
