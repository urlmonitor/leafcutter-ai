## Acceptance Criteria

```gherkin
Given the size standard's published description states which kinds of file it
  covers, when it applies, and how long a file of each kind may be,
When that published description is compared against the outcomes the standard
  actually produces,
Then they agree on all three points, and a change that leaves either the
  description or the enforced behaviour saying something the other does not is
  reported and the commit does not complete,
And every published place that states the rule is compared, so a rule that is
  corrected in one place and left stale in another is reported rather than
  passing on the strength of the corrected one,
And the agreement is established by evaluating both the described rule and the
  produced outcome, not by anyone reading the description and judging it
  correct,
And given the standard accepts, as an input to whether a particular file
  passes, some fact about the change being made to that file,
When the same file at the same length is presented once with that fact holding
  and once with it not holding,
Then either the two presentations produce different verdicts, or the standard
  does not accept that fact as an input to the verdict at all — a fact that is
  accepted for the verdict and then makes no difference to it is not permitted
  to remain.
```
