# When agent cards are absent, the mirror check no-ops instead of false-failing

## Actor / Goal

As the leafcutter-ai system, I want to implement AC `INF-600l-1-i` — When agent cards are absent, the mirror check no-ops instead of false-failing — so that the acceptance criterion is satisfied.

## Context

This ticket was generated from AC store entry `INF-600l-1-i`. Component: `infrastructure`. Assigned agent: `python-coder`. Estimated complexity: `S`.

## Acceptance Criteria

```gherkin
Given a project that has an agent registry but no generated agent cards on disk
  (a consumer that uses the registry but has not generated cards, or a card whose
  expected path does not resolve)
When the extended consistency check runs the card<->registry mirror comparison
Then it treats the absent card as "nothing to compare" and does NOT report a
  mismatch or fail the build for the missing card
And it emits an advisory note (to stderr / log) that the mirror comparison was
  skipped for the agents whose cards were absent, so the skip is visible
And it still runs the registry-internal consistency it already performed (the
  absence of cards does not disable the pre-existing spawn-consistency behavior)
```
