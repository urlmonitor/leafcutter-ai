## Actor / Goal

## Context

## Acceptance Criteria

```gherkin
Given the commit guardian configuration has the diff_coverage section with:
  enabled: true
  strict: true
  min_coverage_percent: 80
  coverage_xml_path: "coverage.xml"
  max_age_seconds: 3600
And the diff-cover binary is installed
And coverage.xml exists but was last modified 7200 seconds ago (exceeds max_age_seconds)
When the diff-cover hook runs at pre-commit time
Then the hook emits a warning to stderr stating that coverage.xml is stale
  (age: 7200s, max allowed: 3600s)
And the hook exits with code 0 (fail-open despite strict mode)
And the warning includes guidance to regenerate the coverage artifact

---

Given the repository is a shallow clone (depth-limited fetch)
And the diff-cover binary is installed
And coverage.xml exists and is fresh
When the diff-cover hook runs at pre-commit time
Then the hook detects the shallow clone condition
And the hook exits with code 0 (fail-open)
And it emits an advisory message explaining that diff-cover requires
  full history and suggesting fetch-depth: 0
```
