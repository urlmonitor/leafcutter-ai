# Every final-gate message names the test-design stage that now owns the final gate

## Actor / Goal

## Context

This ticket was generated from AC store entry `ACD-300c-5`. Component: `ac-driven-dev`. Assigned agent: `python-coder`. Estimated complexity: `S`. Complexity: `low`.

## Acceptance Criteria

```gherkin
Given the final gate of a /plan-feature run now follows the test-design stage, not the
  technical planner's stage,
When the user is shown the final gate, cancels at the final gate, or the final commit fails,
Then the final gate's heading names the test-design stage as the stage it follows,
And the cancel message names the final gate as the test-design gate, as in
  "final gate (test design)", and does not contain "IT-PO" or "IT PO v3",
And the commit-failure message names the stage "test-design", not "it-po",
And the messages for the product owner, business analyst and technical planner gates are
  unchanged, character for character,
And the workflow body's measured length after the change is no greater than before it.
```
