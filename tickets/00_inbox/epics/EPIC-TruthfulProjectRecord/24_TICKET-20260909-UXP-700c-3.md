## Acceptance Criteria

```gherkin
Given a change that touches either the project record or a file the record points at,
When that change is offered to the project's automatic checks,
Then the record's checker runs as one of them,
And the verdict the record's checker reaches is the verdict those checks report for the
  record,
And a change that touches neither the record nor anything the record points at does not run
  the record's checker.
```
