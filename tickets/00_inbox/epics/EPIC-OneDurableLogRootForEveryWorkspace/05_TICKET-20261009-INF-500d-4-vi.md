## Acceptance Criteria

```gherkin
Given a drive is running inside a temporary per-drive workspace that will be
  deleted when the drive finishes,
And an agent in that drive files a report, records a telemetry event, or reads the
  accumulated reports by following the instructions it was shipped with,
When the temporary workspace is subsequently removed,
Then what the agent wrote is still readable afterwards from the durable location
  that outlives the workspace,
And a reader following its shipped instructions finds every one of those logs in
  that one place, not split across a disposable root and an enduring one.
```

## Implementation Notes

```yaml
- 'NO SHIPPED SURFACE CARRIES A LOG DESTINATION OF ITS OWN. Every --jsonl, --log or
  --feedback argument naming debugging/logs/<file> as a workspace-relative path, and
  every ''append to debugging/logs/...'' instruction, must be removed: writers and
  readers now default to the declared location (INF-500d-4-iv, -v). Where an instruction
  genuinely needs to state or show the location, it must obtain it from INF-500d-4-iii''s
  location query and must not restate a path. This is INF-400c-4-i''s rule for the
  knowledge surfaces, applied to feedback and telemetry.'
- 'The signoff skill''s id-capture contract is unchanged: the feedback id is read
  from stdout, and the sidecar recovery grep ''sidecar:[^ ]*feedback_id_[0-9]*.txt''
  still applies. INF-500d-4-ii''s sink line stays on stderr. Callers that redirect
  stderr to a file keep doing so.'
- Telemetry calls in building-epics and the supervisors keep their trailing '|| true'.
  Telemetry stays best-effort (BP-400a-1-i).
- Reader-facing instructions (feedback-report workflow, feedback-analyst, feedback-review,
  feedback-analysis, retrospective-agent) must tell the agent to rely on the reader's
  stated sink and record count (INF-500d-4-v), not to open a hard-coded path.
- DO NOT LAND BEFORE INF-500d-4-iv AND INF-500d-4-v. Removing the overrides first
  sends writes to the old __file__-derived default, which is a third location.
- Apply the Prompt-Quality Checklist. Bash snippets stay single-command per the shell
  convention.
- 'Deployed/template parity (ADR-001): edit the templates and verify the deployed
  copies through the build round-trip.'
```
