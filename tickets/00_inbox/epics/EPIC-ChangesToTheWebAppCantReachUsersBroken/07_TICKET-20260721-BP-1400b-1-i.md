# A web-app file containing an unescaped-entity style error blocks the pull request from merging

## Actor / Goal

As the leafcutter-ai system, I want to implement AC `BP-1400b-1-i` — A web-app file containing an unescaped-entity style error blocks the pull request from merging — so that the acceptance criterion is satisfied.

## Context

This ticket was generated from AC store entry `BP-1400b-1-i`. Component: `build-pipeline`. Assigned agent: `python-coder`. Estimated complexity: `S`. Complexity: `low`.

## Acceptance Criteria

```gherkin
Given a pull request that changes a web-app file (under leafcutter-web/) and
  introduces an unescaped-entity style error — an unescaped character such as a
  raw apostrophe rendered directly in markup, the react/no-unescaped-entities
  class of violation that previously reached users while every check passed,
When the web-app style check runs on that pull request,
Then the check reports a failing result that identifies the unescaped-entity
  violation,
And the pull request is reported as not mergeable while that check is failing.
```

- [ ] AC-1: the check reports a failing result that identifies the unescaped-entity
- [ ] AC-2: the pull request is reported as not mergeable while that check is failing.
