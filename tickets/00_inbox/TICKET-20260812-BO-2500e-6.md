```yaml
- The required CI proof-of-done gate in .github/workflows/ci.yml must invoke the JS
  test runner (vitest) and apply the SAME done-proof engine (scripts/ac_store/done_proof.py)
  used for Python-covered ACs, so its fresh-checkout verdict includes JS-covered ACs.
- 'Deploy-manifest rule (mandatory): any module the required CI gate imports (done_proof.py
  and any new JS-runner helper module) MUST be added to the build deploy map (build_ac_store
  deploy_map in scripts/build_phases.py) so the gate does not crash with ModuleNotFoundError
  once it is a required check; verify by running the deployed gate (build.py then
  the gate), not only source-tree unit tests.'
- The gate's pass/fail must derive from committed branch state only, evaluated on
  a fresh clean checkout, and must fail closed when front-end proof-of-done is failing.
- The gate must remain a required status check and behave identically for Python-covered
  ACs (no regression); the CI job must ensure Node/vitest is available in the runner
  environment so JS-covered ACs are evaluated rather than skipped.
```
