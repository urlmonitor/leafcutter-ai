# Allowlist entries suppress findings only when the allowlist path segments are a suffix of the finding path segments

## Actor / Goal

As the leafcutter-ai system, I want to implement AC `GE-113c-3` — Allowlist entries suppress findings only when the allowlist path segments are a suffix of the finding path segments — so that the acceptance criterion is satisfied.

## Context

This ticket was generated from AC store entry `GE-113c-3`. Component: `guardrail-engine`. Assigned agent: `python-coder`. Estimated complexity: `S`. Complexity: `low`.

## Acceptance Criteria

```gherkin
Given the secrets scanner processes a finding at a file path,
And an allowlist entry specifies a path for that finding's rule,
When the scanner evaluates whether the allowlist entry suppresses the finding,
Then the finding is suppressed only when one of the following holds:
  - the allowlist path is the literal wildcard "*",
  - the allowlist path segments match the finding path segments exactly, or
  - the allowlist path segments are a segment-by-segment suffix of the finding
    path segments (e.g. allowlist "config/secrets.py" suppresses a finding at
    "src/config/secrets.py" but NOT at "other/secrets.py"),
And basename equality alone is never sufficient to suppress a finding when
  the allowlist entry contains a path separator.
```
