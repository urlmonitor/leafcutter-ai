# Author bundled fixture tree for all 8 Atlas views

## Actor / Goal

As the Leafcutter Atlas reviewer, I want the app to render populated content from
bundled fixtures when mock mode is active, so I can demo and test the Atlas without
needing a live repo checkout.

## Acceptance Criteria

- Given mock mode active, when the /roadmap view loads, then it shows 3 phases from
  the fixture docs/roadmap.json.
- Given mock mode active, when the /flows view loads, then it shows at least 2 flows
  from the fixture product-truth store.
- Given mock mode active, when the /atlas view loads, then it shows ACs from the
  fixture acceptance-criteria store.
