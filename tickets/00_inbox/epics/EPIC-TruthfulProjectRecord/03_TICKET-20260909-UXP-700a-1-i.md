# An absent start-up input is named, not crashed on

## Actor / Goal

## Context

## Acceptance Criteria

```gherkin
Given a freshly installed record in which the classifier evaluation set has never been
  authored, so the input the checker expects to read is absent,
When the record's checker runs,
Then it names the absent input and the artifact class that input belongs to as a reported
  condition,
And it reaches a stated verdict rather than terminating with an unhandled failure,
And the verdict it reaches is not the verdict it reports for a record it checked and found
  sound.
```

- [ ] AC-1: it names the absent input and the artifact class that input belongs to as a reported
- [ ] AC-2: it reaches a stated verdict rather than terminating with an unhandled failure
- [ ] AC-3: the verdict it reaches is not the verdict it reports for a record it checked and found
