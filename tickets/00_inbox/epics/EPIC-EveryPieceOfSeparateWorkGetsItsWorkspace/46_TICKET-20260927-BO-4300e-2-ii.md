# A workspace with a program still running inside it is never left half-cleared

## Actor / Goal

As the leafcutter-ai system, I want to implement AC `BO-4300e-2-ii` — A workspace with a program still running inside it is never left half-cleared — so that the acceptance criterion is satisfied.

## Context

This ticket was generated from AC store entry `BO-4300e-2-ii`. Component: `build-orchestration`. Assigned agent: `python-coder`. Estimated complexity: `M`. Complexity: `medium`.

## Acceptance Criteria

```gherkin
Given a workspace holding nothing unsent, in which a program started from the
  workspace is still running and holding files open,
When the workspace is cleared,
Then either the program is stopped and no part of the workspace remains, or
  the request is refused naming the program and the workspace is identical
  before and after,
And the answer never states the workspace was cleared while any part of it
  remains.
```

- [ ] AC-1: either the program is stopped and no part of the workspace remains, or
- [ ] AC-2: the answer never states the workspace was cleared while any part of it
