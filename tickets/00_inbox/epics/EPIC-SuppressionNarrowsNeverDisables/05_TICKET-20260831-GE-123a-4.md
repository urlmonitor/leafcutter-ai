## Acceptance Criteria

```gherkin
Given the reference document that lists the secrets check's detection rules and
  introduces them as a sequence the scanner applies in order,
When a reader wants to know whether a file the scanner recognises by its name is
  also read through line by line,
Then the reference states that recognising a file by its name RECORDS a result
  and the content rules still run afterwards, and that the name rule is not a
  stopping point in the sequence,
Because the list as written implies an order and says nothing about any rule
  ending the scan, so a reader has no way to tell the two apart — and the reading
  that ends the scan is the one that produced the measured coverage collapse.

Given the same reference,
When a reader wants to know what an environment-named file will be reported for,
Then the reference states that such a file yields the name-based result PLUS
  whatever the content rules find in it, that the two are separate results, and
  that quieting the name-based result therefore leaves every content-based result
  reported,
And it states that a file of that kind carrying nothing the content rules
  recognise is still reported for its name alone,
Because the whole value of the change is that a single instruction about the name
  no longer decides what the file's contents are examined for, and a reader who
  cannot see that in the reference will keep writing the instruction expecting the
  old outcome.

Given the same reference,
When the reader compares it against the check as it behaves,
Then every behaviour the reference attributes to the name rule is one the check
  actually has, and every behaviour the check has around that rule is one the
  reference does not omit,
And where the two disagree the implementation is authoritative and the
  disagreement is raised as a defect rather than written down as fact,
Because a reference that overstates the coverage is the same failure as the
  defect this feature removes — an author who believes a file is being examined
  when it is not — and one that understates it sends the author looking for a
  protection they already have.
```
