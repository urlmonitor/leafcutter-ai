## Acceptance Criteria

```gherkin
Given a project whose record already holds at least one journey, one example dataset and one
  screen, all authored by that project,
When the tooling is installed into the same project a second time,
Then every pre-existing artifact has the same content after the install as before it,
And the store index still lists exactly the artifacts it listed before the install,
And any scaffold the install would otherwise write is left untouched wherever a file of that
  name already exists.
```
