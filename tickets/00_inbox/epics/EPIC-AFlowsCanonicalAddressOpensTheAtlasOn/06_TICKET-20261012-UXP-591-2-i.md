## Implementation Notes

```yaml

  the flow id decides a 404.'
- The 'Step not found' notice derives from the current address (a flow is drawn AND
  ?step= is present AND names no step or branch of it). It is not an independent flag,
  so it cannot outlive the unknown value (owner ruling 2, UXP-591-2-ii).
- Notice copy is the dataset's FlowRoute.step_notice text; the step value is rendered
  as React text only (attacker-controlled input).
- 'The address stays as opened, ?step=lint included: no replace on load.'
```
