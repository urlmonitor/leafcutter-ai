# Each declared surface is validated for the relationship kinds it promises

## Actor / Goal

## Context

## Acceptance Criteria

```gherkin
Given a surfaces configuration where each declared surface lists the relationship
  fields (edge_fields) it claims to contribute
When the knowledge map is validated
Then for every declared surface, the validation checks that surface against the
  exact edge_fields it declares — not against a fixed expected list of relationship
  kinds
And a surface that declares an empty edge_fields list is accepted as contributing
  no edges
And the validation iterates over whatever set of surfaces is declared, so adding
  or removing a surface changes the set checked without any edit to the validation
  rule
```
