# A step skipped because its state is already satisfied still reports the skip and why

## Actor / Goal

As the leafcutter-ai system, I want to implement AC `BO-1000a-3` — A step skipped because its state is already satisfied still reports the skip and why — so that the acceptance criterion is satisfied.

## Context

This ticket was generated from AC store entry `BO-1000a-3`. Component: `build-orchestration`. Assigned agent: `python-coder`. Estimated complexity: `M`. Complexity: `medium`.

## Acceptance Criteria

```gherkin
Given a step's required outcome is already satisfied before it runs (for
  example a pull request is already open, the branch is already up to date
  with the mainline, the closure commit already exists, the pull request is
  already merged, or the worktree is already absent),
When finalize reaches that step,
Then finalize still emits a start line for the step that reports the step is
  being skipped and states the already-satisfied condition that caused the
  skip,
And a skipped step is never silently omitted from the progress output.
```
