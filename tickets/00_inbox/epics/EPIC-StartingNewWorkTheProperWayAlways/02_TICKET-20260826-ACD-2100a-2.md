## Acceptance Criteria

```gherkin
Given a copy of the worktree setup step placed in a directory that is not inside
  any git repository and has no repository among its ancestors,
And exactly one git repository exists among the immediate subdirectories of that
  directory,
When the setup step is executed from that directory with no repository location
  supplied by the caller,
Then it resolves the repository it operates on to that one repository,
And it exits successfully with the requested worktree present on disk under that
  repository,
And it states on its error stream which repository it selected and that the
  selection came from a search rather than from the script's own location.
```

## Implementation Notes

```yaml
- The change must land under templates/scripts/. The deployed copy under .leafcutter/scripts/
  is build output and was already patched by hand once on 2026-08-18; that patch was
  regenerated away.
- The anchor-based resolution must remain the first choice; the search is a fallback
  that runs only when the anchor yields no repository. A change that makes the search
  primary alters behaviour for every caller that works today.
- 'The search must be bounded: immediate subdirectories of the starting directory
  only. It must not walk upward past the starting directory and must not follow symlinks
  out of it -- an unbounded walk on a developer machine can reach unrelated repositories
  and is a denial-of-service surface on a deep tree.'
- The fallback must announce itself on the diagnostic stream at WARNING or higher
  and name the repository it selected. A silent fallback is indistinguishable from
  the anchor having worked and leaves the next wrong-repository incident undiagnosable.
- 'Must satisfy the repository error-handling policy: the git invocation is external
  I/O and must be wrapped in a typed except that logs at WARNING or re-raises; it
  must not be swallowed.'
- Must not change behaviour for callers that supply an explicit repository location
  -- that path must not consult the anchor or the search at all.
- 'The resolution must be idempotent: two runs from the same directory with the same
  layout select the same repository.'
```
