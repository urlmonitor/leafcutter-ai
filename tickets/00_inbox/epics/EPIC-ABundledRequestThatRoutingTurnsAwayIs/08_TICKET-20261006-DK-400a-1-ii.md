## Implementation Notes

```yaml
- Gap accounting for the request itself (the split subject) is decided when the split's
  outcome is known, never at detection. Approved -> no unsupported or ambiguous gap
  observation for the request itself. Trigger jev_none rejected, too few parts or
  an abandoned proposal (DK-400c-3, DK-400c-1-ii) -> exactly today's unsupported observation
  (same gap_key, gap_type and fields, fallback_outcome blocked) and capability_gap_recorded
  true. Trigger ambiguous rejected, too few parts or abandoned -> no gap while today's
  clarification question is open; today's ambiguous observation only if that clarification
  ends unresolved (the person cannot be asked, or intent.max_clarifications is reached),
  exactly as today. bundled_accepted or mid_run -> never a gap for the request itself.
  Run cancelled before the gate answer -> no gap for the request itself (mock-data
  v6 invariant on capability_gap_recorded).
- 'The host.decompose_goal operation records no host_only gap observation: it is the
  split''s coordination step, not a build opportunity, and recording it would list
  the subject''s goal tokens as a build opportunity.'
- '''No capability-gap record for the request itself'' (the BA''s final-gate wording)
  scopes the rule: observations from a part''s own work (its research, options or
  synthesis host operations, a no_match of a part''s child) are recorded exactly as
  a stand-alone run of that part would record them, attributed to the part''s request
  and never to the split subject.'
- A single question no capability can meet produces today's gap observation unchanged
  (gap_key, gap_type, normalized_need, fallback_outcome), so occurrence counts across
  runs stay comparable before and after this feature.
- 'Tests enable splitting explicitly: split.enabled true through a config override
  (false only where a test compares with the off switch). None relies on the shipped
  default, which stays false until E3 merges (dec-9925ebf1895222f4, see DK-400a-1).
  A test asserting that no split starts must run with splitting on, or it passes for
  the wrong reason.'
```
