## Acceptance Criteria

```gherkin
Given the product-owner stage has committed its L0/L1 files to the authoring
  branch and the business-analyst stage is interrupted before it commits
  (process killed, machine crash, or user closes the session),
When the user starts the authoring workflow again for the same feature,
Then the L0/L1 files committed by the completed stage are still present on the
  authoring branch and are not lost,
And the workflow resumes from the first stage that had not committed
  (the business-analyst stage) rather than redoing the completed stage,
And no completed-stage work has to be re-authored from scratch.
```
