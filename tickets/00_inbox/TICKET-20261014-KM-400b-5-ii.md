## Acceptance Criteria

```gherkin
Given generation G32 is the active generation of repository R1
And a publication of G33 for R1 has stored 10,700 nodes and 28,000 relationships tagged to G33
And the publication fails because its count check reports 28,814 relationships expected and 28,813 kept
When the removal of G33 is refused because the store has become read-only
Then the operation reports failure
And the result carries the original cause: the count check, relationships, 28,814 expected and 28,813 kept
And the result separately states that the failed generation was not removed, naming repository R1 and generation G33
And the result states the refusal received for the removal
And the result states how many nodes and relationships tagged to G33 remain, or states that the remaining amount could not be determined, never 0
And G32 is still the active generation of R1

Given the removal of G33 deletes the nodes but is refused before the relationships are removed
When the operation returns
Then the result names G33 as partially removed and states which kinds remain

Given the store refuses both the removal and the request to count what remains
When the operation returns
Then the result names G33 as not removed and the remaining amount as undetermined, naming the refusal
And the result is distinguishable from a failure in which G33 was removed
```
