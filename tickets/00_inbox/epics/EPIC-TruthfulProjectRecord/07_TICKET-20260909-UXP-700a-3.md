  (the AC-1/AC-2-still-hold-after-the-flag check at the bottom of the test). It
  computes `other_products = {p.parts[0] for p in place.iterdir() if p.is_dir()} -

  with `p.name` (the direct child's own name; `place.iterdir()` already yields
  only immediate children). Classification: test_drift — python-coder verified
  the real implementation is correct (a fresh `python scripts/build.py
  --target-dir <tmp> --seed-example-product fern-and-fig` run leaves exactly

  `mockups/`; see the python-coder sign-off comment below for the manual
  verification transcript), so this is an assertion-only fix — no production
  change is needed or should be made for this task.
