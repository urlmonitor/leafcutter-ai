## Acceptance Criteria

```gherkin
Given a journey whose authoritative description lives in the journey itself,
When a shorter form of that description is needed for a place that cannot show the whole of
  it,
Then the shorter form is produced from the authoritative one at the time it is needed,
And no second, separately authored description of the same journey exists anywhere in the
  record,
And changing the authoritative description changes every place the shorter form appears, with
  no other edit,
And a second authored description introduced anywhere in the record is reported, naming the
  journey and both places its description is held.
```
