# No setting can put every path on the warn tier at once

## Actor / Goal

## Acceptance Criteria

```gherkin
Given a configuration that attempts to place the whole repository on the warn
  tier — a bare wildcard entry, a repository-root entry, or a global
  warn-everywhere switch
When the commit-tier declaration check loads its configuration
Then the configuration is rejected and the reason names the entry that was
  refused
And the check continues with block as the default for every path

Given the warn list names three specific directories
When a file outside all three has no component-level declaration and is staged
Then the verdict for that file is "block", never "warn"
```

- [ ] AC-1: the configuration is rejected and the reason names the entry that was
- [ ] AC-2: the check continues with block as the default for every path
- [ ] AC-3: the verdict for that file is "block", never "warn"

## Implementation Notes

```yaml
- REFUSE THE ENTRY, DO NOT SILENTLY DROP IT. A wildcard that is quietly ignored leaves
  the author believing the whole repository is on warn while it is not, producing
  the opposite surprise later. The refusal must name the offending entry and state
  that the warn tier is per-path by design.
- 'THE REFUSED SET IS ENUMERATED, NOT PATTERN-GUESSED: a bare wildcard (`*`, `**`,
  `**/*`), the repository root (``, `.`, `/`, `./`), and any global switch key (e.g.
  a `warn_all` or `enforcement_mode` key in the frontend_ac_declaration section).
  The third is the important one — the blanket escape arrives as a NEW KEY, not as
  a clever list entry, so the config loader must reject unknown enforcement-shaped
  keys rather than ignoring them.'
- REFUSING THE CONFIG MUST NOT DISABLE THE CHECK. After the refusal the run continues
  with block as the default for every path, including the other, legitimate warn_paths
  entries if any. An implementation that aborts on bad config turns a rejected wildcard
  into a bypass.
- THIS IS DISTINCT FROM GE-124g-1-i AND BOTH ARE NEEDED. Here the refusal is about
  WHETHER A FILE MUST DECLARE; there it is about WHAT A DECLARATION IS WORTH. Two
  different configuration surfaces, two different rules, and GE-124g-1-i's third scenario
  explicitly states that this escape does not reach the four GE-124g places.
```
