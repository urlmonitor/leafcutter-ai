```gherkin
Given a run whose root goal is the single question "Which retention period should the
  kernel's Langfuse traces use?",

And the person is asked no question about splitting,
And the run goes on as one decision from the precedent step,
And the run's report has no split section.
```

## Implementation Notes

```yaml
- 'A not-bundled single question reaches exactly today''s interactions: the same envelope
  sequence and the same Jev batches apart from the one added bundle question, no split
  record, and no split section in report.md.'
- The check adds no provider call and no host operation to this run (see DK-400a-1).
- 'The no-split outcome is recorded once per item: the item''s split_checked flag
  (DK-400c-3, ADR-067 Open Question 1) is set when its bundle question is asked, so
  the question is never asked again on a continuation or retry of the same item.'
- 'Tests enable splitting explicitly: split.enabled true through a config override
  (false only where a test compares with the off switch). None relies on the shipped
  default, which stays false until E3 merges (dec-9925ebf1895222f4, see DK-400a-1).
  A test asserting that no split starts must run with splitting on, or it passes for
  the wrong reason.'
```
