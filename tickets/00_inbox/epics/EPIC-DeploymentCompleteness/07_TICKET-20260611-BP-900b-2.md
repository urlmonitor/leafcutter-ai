# Guard cross-checks extracted references against the deployable script manifest

## Actor / Goal

As the leafcutter-ai system, I want to implement AC `BP-900b-2` — Guard cross-checks extracted references against the deployable script manifest — so that the acceptance criterion is satisfied.

## Context

## Acceptance Criteria

```gherkin
Given the guard has extracted the set of referenced script paths from compiled templates,
When it compares each reference against the set of scripts that build.py will deploy
(i.e. scripts listed in build_phases that are copied to {target}/.leafcutter/scripts/
and shimmed to {target}/scripts/),
Then every reference that matches a deployed script path is marked as resolved
And every reference that does NOT match a deployed script path is marked as broken
And the guard produces a list of zero or more broken references
```
