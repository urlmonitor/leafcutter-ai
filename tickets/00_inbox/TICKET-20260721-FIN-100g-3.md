## Acceptance Criteria

```gherkin
Given the finalize workflow is invoked with a target "ge-116a-1" (supplied as a
bare string or as an object) that resolves to no registered worktree — no
worktree currently has that branch checked out
When the pre-flight fails to resolve the supplied target to a worktree
Then it exits with a single actionable error that:
  - identifies the unresolved target "ge-116a-1" by name
  - names the expected argument forms (a bare branch-name string, OR an object
    with a target/target_branch key)
  - lists the candidate worktrees and their checked-out branches that ARE
    currently registered (for example the entries from `git worktree list`)
And this error is emitted whenever a target was supplied but is unresolvable —
it is distinct from, and more specific than, the generic "clear error naming
the branch" of FIN-100g-1
```
