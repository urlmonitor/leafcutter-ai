# A durable-side-effect work item requires a test that exercises the real effect, not only that a step ran

## Acceptance Criteria

```gherkin
Given a work item declares a durable, observable side-effect (an artifact written to
  disk that can be read back),
And its test evidence consists solely of tests asserting that a step was dispatched —
  the presence, labels, or counts of dispatched helpers,
When the test-evidence sufficiency check evaluates coverage for the work item,
Then it reports the side-effect as uncovered, because dispatch-only evidence proves a
  step ran but not that the effect occurred,
And the same work item satisfies the check once its evidence includes at least one test
  that produces the artifact and then reads it back (a round-trip of the real effect).
```
