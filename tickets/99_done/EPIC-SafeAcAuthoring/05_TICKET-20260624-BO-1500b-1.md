# Each authoring stage commits its AC files before the next stage starts

## Actor / Goal

As the leafcutter-ai system, I want to implement AC `BO-1500b-1` — Each authoring stage commits its AC files before the next stage starts — so that the acceptance criterion is satisfied.

## Context

This ticket was generated from AC store entry `BO-1500b-1`. Component: `build-orchestration`. Assigned agent: `python-coder`. Estimated complexity: `M`.

## Acceptance Criteria

```gherkin
Given the authoring pipeline runs its stages in order
  (product-owner, then business-analyst, then it-po),
When a stage finishes producing its AC YAML files and the user approves it,
Then those files are committed to the authoring branch before the next stage
  begins,
And after the product-owner stage commits, the authoring branch HEAD contains
  the L0/L1 files even though the business-analyst stage has not yet started,
And each subsequent stage's commit adds that stage's files on top of the
  prior stage's commit.
```
