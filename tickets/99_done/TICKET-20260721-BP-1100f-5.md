# A work item declaring a durable side-effect is routed through the smoke check automatically

## Actor / Goal

As the leafcutter-ai system, I want to implement AC `BP-1100f-5` — A work item declaring a durable side-effect is routed through the smoke check automatically — so that the acceptance criterion is satisfied.

## Context

This ticket was generated from AC store entry `BP-1100f-5`. Component: `build-pipeline`. Assigned agent: `python-coder`. Estimated complexity: `M`. Complexity: `medium`.

## Acceptance Criteria

```gherkin
Given a work item declares a durable, observable side-effect (an artifact written to disk),
And an observable-side-effect smoke check exists in the pipeline,
When the pipeline runs the work item's verification phase,
Then the smoke check runs automatically for that work item — selected by its declared
  side-effect rather than by an opt-in flag — and produces a smoke result,
And the work item cannot reach a done state with the smoke check left unrun or silently
  skipped.
```

- [ ] AC-1: an observable-side-effect smoke check exists in the pipeline
- [ ] AC-2: the smoke check runs automatically for that work item — selected by its declared
- [ ] AC-3: the work item cannot reach a done state with the smoke check left unrun or silently
