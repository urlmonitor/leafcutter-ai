# Mock mode seam: repoRoot() returns fixture root when LEAFCUTTER_MOCK=1

## Actor / Goal

As the Leafcutter Atlas, I want `repoRoot()` to return the bundled fixture repo root
when `LEAFCUTTER_MOCK=1` is set, so that all 8 Atlas views render from curated fixture
data without any per-loader mock branches.

## Acceptance Criteria

- Given `LEAFCUTTER_MOCK=1`, when any Atlas loader calls `repoPath()`, then the path
  resolves inside `leafcutter-web/fixtures/`.
- Given `LEAFCUTTER_MOCK_LOCK=real`, when any runtime override is present, then the
  seam ignores the override and returns the live repo root.
- Given no env var or cookie, when the Atlas loads, then the live repo root is used.
