# Guard extracts script path references from all compiled agent templates and skill files

## Actor / Goal

As the leafcutter-ai system, I want to implement AC `BP-900b-1` — Guard extracts script path references from all compiled agent templates and skill files — so that the acceptance criterion is satisfied.

## Context

This ticket was generated from AC store entry `BP-900b-1`. Component: `build_pipeline`. Assigned agent: `python-coder`. Estimated complexity: `M`.

## Acceptance Criteria

```gherkin
Given build.py has compiled agent templates and skill files to the output directory,
When the post-compile validation phase runs,
Then it scans every .md file in the compiled agents/ and skills/ directories
And it extracts paths matching these patterns:
  - "python3 scripts/<path>" and "python scripts/<path>"
  - "sys.path.insert(<N>, 'scripts/<path>')"
  - "sys.path.insert(<N>, \"scripts/<path>\")"
And the extracted set includes at minimum "scripts/ac_store/ac_prioritizer.py",
  "scripts/ac_store/generate_ticket_from_ac.py", "scripts/goal_to_epic.py"
  when those references exist in the compiled output
```
