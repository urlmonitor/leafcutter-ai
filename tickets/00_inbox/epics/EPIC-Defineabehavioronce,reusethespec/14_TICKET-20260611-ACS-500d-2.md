# Existing page deviations survive pattern updates unchanged

## Actor / Goal

As the leafcutter-ai system, I want to implement AC `ACS-500d-2` — Existing page deviations survive pattern updates unchanged — so that the acceptance criterion is satisfied.

## Context

This ticket was generated from AC store entry `ACS-500d-2`. Component: `ac-store`. Assigned agent: `python-coder`. Estimated complexity: `S`.

## Acceptance Criteria

```gherkin
Given a page AC has implements_pattern: "PTN-001" (paginated-collection),
And a separate deviation AC exists for that page overriding one behavior
  (e.g. "status column uses priority sort order instead of alphabetical"),
When the pattern AC (PTN-001) is amended to add a new behavior
  (e.g. "displays loading skeleton during fetch"),
Then the page inherits the new loading-skeleton behavior from the pattern,
And the existing deviation AC remains unchanged and still overrides
  the specific behavior it was written for,
And no conflict or merge error occurs between the deviation and the
  updated pattern.
```
