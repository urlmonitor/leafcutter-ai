# Agent registry entries use canonical names without version suffixes

## Actor / Goal

As the leafcutter-ai system, I want to implement AC `ACD-1100b-2` — Agent registry entries use canonical names without version suffixes — so that the acceptance criterion is satisfied.

## Context

This ticket was generated from AC store entry `ACD-1100b-2`. Component: `ac-driven-dev`. Assigned agent: `python-coder`. Estimated complexity: `S`.

## Acceptance Criteria

```gherkin
Given the agent registry previously contained entries with ids
  "product-owner-v3", "business-analyst-v3", and "it-po-v3",
When the v2.0 migration promotes v3 agents,
Then config/agent_registry.json contains entries with ids:
  "product-owner" (replacing product-owner-v3)
  "business-analyst" (replacing business-analyst-v3, distinct from the
    removed v1 business-analyst)
  "it-po" (replacing it-po-v3, distinct from the removed v1/v2 it-po)
And each promoted entry's template_path field references the canonical
  filename (e.g. "templates/agents/product-owner.md")
And no entry in the entire registry has an "id" field containing the
  substring "-v1", "-v2", or "-v3".
```
