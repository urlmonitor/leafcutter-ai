# Existing orphaned children are detected and reported by a store-wide scan

## Actor / Goal

## Context

## Acceptance Criteria

```gherkin
Given the AC store at docs/acceptance-criteria/ contains 80+ AC YAML files,
And at least 4 child ACs exist whose parent's covered_by field does not
  include them (e.g. ACS-300h has covered_by: [] but ACS-300h-1.yaml,
  ACS-300h-2.yaml, ACS-300h-3.yaml exist on disk),
When an operator runs the store-wide integrity scan,
Then the scan reports each orphaned child AC with:
  - the child AC ID
  - the expected parent AC ID
  - the parent file path
And the report groups orphans by parent for readability,
And the scan exits with a non-zero status when orphans are found,
And the scan exits with zero status when every child is listed
  in its parent's covered_by field.
```
