# Each finalize step emits a one-line outcome result after its work, on the success path

## Actor / Goal

As the leafcutter-ai system, I want to implement AC `BO-1000b-1` — Each finalize step emits a one-line outcome result after its work, on the success path — so that the acceptance criterion is satisfied.

## Context

This ticket was generated from AC store entry `BO-1000b-1`. Component: `build-orchestration`. Assigned agent: `python-coder`. Estimated complexity: `M`. Complexity: `medium`.

## Acceptance Criteria

```gherkin
Given the finalize-feature workflow runs a step to completion on the success
  path,
When the step finishes its work,
Then a one-line outcome result is emitted for that step describing what the
  step actually did (for example: baseline captured with the count of
  pre-existing failures, pull request opened with its number, mainline merged
  cleanly, tests passed with counts, tickets and source ACs closed with
  counts, pull request merged, local mainline synced, worktree removed),
And this outcome line is distinct from, and additional to, the start-of-step
  announcement for the same step,
And an outcome line is produced for every non-error step, not only for steps
  that hit an error branch.
```
