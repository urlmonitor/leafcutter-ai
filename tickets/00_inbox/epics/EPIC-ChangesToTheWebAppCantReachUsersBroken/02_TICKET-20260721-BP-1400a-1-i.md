# A web-app change that introduces a TypeScript type error is blocked from merging

## Actor / Goal

As the leafcutter-ai system, I want to implement AC `BP-1400a-1-i` — A web-app change that introduces a TypeScript type error is blocked from merging — so that the acceptance criterion is satisfied.

## Context

This ticket was generated from AC store entry `BP-1400a-1-i`. Component: `build-pipeline`. Assigned agent: `python-coder`. Estimated complexity: `S`. Complexity: `low`.

## Acceptance Criteria

```gherkin
Given a pull request that changes a file under the web-app directory
  (leafcutter-web/) and introduces a TypeScript type error — for example,
  assigning a value of the wrong type to a typed variable so the type-check no
  longer succeeds,
When the web-app build/type-check check runs on that pull request,
Then the check reports a failing result,
And the pull request is reported as not mergeable while that check is failing.
```

- [ ] AC-1: the check reports a failing result
- [ ] AC-2: the pull request is reported as not mergeable while that check is failing.

## Implementation Notes

