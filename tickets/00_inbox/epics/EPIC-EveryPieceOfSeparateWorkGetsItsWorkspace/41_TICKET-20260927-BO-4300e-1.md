# Asking where a piece of work's workspace is gets a definite answer from the same maker

## Actor / Goal

As the leafcutter-ai system, I want to implement AC `BO-4300e-1` — Asking where a piece of work's workspace is gets a definite answer from the same maker — so that the acceptance criterion is satisfied.

## Context

This ticket was generated from AC store entry `BO-4300e-1`. Component: `build-orchestration`. Assigned agent: `python-coder`. Estimated complexity: `M`. Complexity: `medium`.

## Acceptance Criteria

```gherkin
Given a project with ready workspaces for "alpha", "alpha-v2" and "beta", none
  for "gamma", and version control's own list of linked workspaces for the
  project empty,
When "alpha", "beta" and "gamma" are each looked up through the workspace
  maker, from the project's top folder and from the folder above it,
Then "alpha" and "beta" are each answered with their own location, the same
  from both starting folders,
And "gamma" is answered with a definite statement that no workspace exists for
  it,
And the lookup of "alpha" never returns the location of "alpha-v2".
```

- [ ] AC-1: "alpha" and "beta" are each answered with their own location, the same
- [ ] AC-2: "gamma" is answered with a definite statement that no workspace exists for
- [ ] AC-3: the lookup of "alpha" never returns the location of "alpha-v2".
