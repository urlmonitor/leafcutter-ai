## Implementation Notes

```yaml
- THE DECLARATION IS A FIRST-CLASS PER-TEST MARKER THE RUNNER READS, and it must be
  REGISTERED in pytest.ini's `markers` section. An unregistered marker is silently
  ignored under some configurations, which would make a typo in a reader declaration
  indistinguishable from an honest omission — and the omission path is the unshared
  one, so the typo would silently cost 59.8s rather than erroring.
- UNDECLARED MUST BE SAFE AND LOUD, NOT SAFE AND SILENT. The undeclared test runs
  (fail-safe, not fail-fast, on the BA's recorded decision), receives its own copy,
  and is named by node id in the run's own record along with a count of how many such
  tests there were. Without the count the 77-site migration has no progress measure.
- 'THE UNDECLARED COUNT IS REPORTED ALONGSIDE TQ-600a-6''S BOUND AND IS EXCLUDED FROM
  IT. As of TQ-600a-6''s 2026-09-28 amendment the second term of that bound is DECLARED
  mutators only, so the undeclared figure this AC produces must be emitted as a named
  field of its own in the run''s record, beside the bound and never folded into its
  allowance. Say so explicitly in the implementation: adding it back into the second
  term restores exactly the defect the amendment removed, in which the bound was loosest
  at the moment the migration was least done. The consequence is intended and must
  not be read as a conflict with this record — an undeclared test still runs, still
  passes and is still merely named HERE, while the same test BREAKS the bound on TQ-600a-6
  and is named as an offender by TQ-600a-8''s examination. Fail-safe at run time on
  this record, fail-loud on the audit surface and at commit time.'
- THE ROUTE MUST BE DECIDABLE AT FIXTURE-REQUEST TIME from the test item's metadata,
  without importing or executing the test body.
- 'ROUTING MUST NOT CONSULT THE TEST''S LOCATION OR ITS NAME, for either branch. The
  cheapest wrong implementation — "anything matching test_bp_900g_8* gets its own
  copy" — satisfies TQ-600a-1 and TQ-600a-2 as written and fails the moment a fifth
  mutator appears under another name. Verified at enrichment: that glob was a proxy
  for the known mutators, never a verified complete set.'
- An undeclared test must never be failed, errored or skipped by the routing itself.
  The cost of the safe default is one extra 59.8s deploy until somebody labels it;
  the reported name is what stops that becoming permanent.
```
