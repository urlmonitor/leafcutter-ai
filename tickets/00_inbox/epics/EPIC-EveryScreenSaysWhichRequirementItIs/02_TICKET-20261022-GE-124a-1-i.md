## Acceptance Criteria

```gherkin
Given a staged screen component file that has no leading comment block
When the frontend declaration reader evaluates the file
```

## Implementation Notes

```yaml
- 'THE VERDICT IS DRIVEN BY THE @ac LINE, NOT BY THE PRESENCE OF A COMMENT. declaration_block
  must be recorded as null whenever no @ac line is found in the leading comment region,
  so the mock-data if-and-only-if holds exactly: declares == [] iff declaration_block
  == null. A reader that stores a prose header in declaration_block while leaving
  declares empty breaks that invariant and makes every downstream consumer''s null-check
  unreliable.'
- '''missing'' is a first-class verdict value in the shared reader''s enum, distinct
  from the absence of a record. An in-scope staged file always yields a record; only
  an out-of-scope file (GE-124a-3) yields none.'
- No inference from filename, export name, or directory. A file with no @ac line declares
  nothing, whatever it is called — inferring a criterion would manufacture the false
  traceability GE-124g exists to prevent.
```
