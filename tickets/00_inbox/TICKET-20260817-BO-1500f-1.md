# The isolated-workspace setup step is dispatched only to an agent permitted to run repository commands

## Actor / Goal

As the leafcutter-ai system, I want to implement AC `BO-1500f-1` — The isolated-workspace setup step is dispatched only to an agent permitted to run repository commands — so that the acceptance criterion is satisfied.

## Context

This ticket was generated from AC store entry `BO-1500f-1`. Component: `build-orchestration`. Assigned agent: `python-coder`. Estimated complexity: `S`. Complexity: `low`.

## Acceptance Criteria

```gherkin
Given an AC-authoring run reaches the step that sets up its isolated authoring workspace,
And that step must run repository commands (fetch, create a branch from the tip of the
  shared main line, and add a separate working copy),
When the workflow dispatches the step,
Then it dispatches it to an agent whose registered charter permits running repository
  and shell commands,
And it does not dispatch it to a read-only reporting agent whose charter excludes
  running commands,
And when the configured target for that step is an agent whose charter excludes running
  repository commands, the run stops before any authoring agent is dispatched and reports
  the mis-assignment, naming both the step and the agent it was pointed at.
```
