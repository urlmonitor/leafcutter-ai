# diff-cover hook warns on stale coverage artifact and degrades gracefully in shallow clones

## Acceptance Criteria

```gherkin
Given the commit guardian configuration has the diff_coverage section with:
  enabled: true
  strict: true
  min_coverage_percent: 80
  coverage_xml_path: "coverage.xml"
  max_age_seconds: 3600

And coverage.xml exists and is fresh
When the diff-cover hook runs at pre-commit time
Then the hook detects the shallow clone condition
And the hook exits with code 0 (fail-open)
And it emits an advisory message explaining that diff-cover requires
  full history and suggesting fetch-depth: 0
```
