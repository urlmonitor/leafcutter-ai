## Acceptance Criteria

```gherkin
Given goal_to_epic.py is invoked non-interactively (no controlling TTY on
  standard input) with an explicit approval flag (for example --yes or
  --approved-only),
When execution reaches the readiness gate that would otherwise prompt the user,
Then the command proceeds past the gate without prompting for input,
And the command does not exit non-zero merely because no interactive input is
  available,

  already-approved leaf ACs and excludes the unapproved ones.

  with no approval flag supplied,
When execution reaches the readiness gate,
Then the command exits with a non-zero status and prints a clear message
  stating that approval input is required and naming the flag to pass, rather
  than hanging waiting for input that can never arrive.

Given goal_to_epic.py is invoked interactively (a TTY is present) with no
  approval flag,
When execution reaches the readiness gate,
Then the existing interactive prompt behavior is unchanged.
```
