## Acceptance Criteria

```gherkin
Given the declared retention bound is at most 3 retained generations and a minimum retirement age of 24 hours
And the repository holds 12 generation records
And 123,810 entity nodes each name a generation, and every generation so named has a record
When the retention policy is evaluated
Then the evaluation reports that 0 entity nodes name a generation with no record
And it reports that figure explicitly rather than leaving it out
And it reports the entity-node count attributed to each of the 12 generation records, summing to 123,810

Given 400 entity nodes name a generation for which no generation record exists
When the retention policy is evaluated
Then the evaluation reports that 400 entity nodes name a generation with no record, and names the generations they refer to
And those 400 nodes are reported as unaccounted for, and are reported neither as reclaimable nor as belonging to any generation that received a verdict
And every generation that does have a record still receives its own reclaimability verdict

Given 400 entity nodes name a generation with no record, and a further 200 such nodes are added
When the retention policy is evaluated again
Then the reported unaccounted figure is 600

Given the repository holds 12 generation records and no entity node names any generation
When the retention policy is evaluated
Then the evaluation reports an entity-node count of 0 for each of the 12 generation records
And it reports 0 unaccounted nodes
And a generation record with 0 attributed nodes is not reported as unaccounted for
```
