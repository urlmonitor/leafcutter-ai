## 1. Names and shapes

Per-entry keys (new optional properties of the `test_spec` array items in `config/ac_store_schema.json`, beside `must_catch`, `angle` and `surface_invoked`; `additionalProperties: false` stays):

| key | JSON shape | rule |
|---|---|---|
| `proves_clause` | string, minLength 1 | The outcome clause the entry proves: the verbatim `test_intent[].clause` text, never trimmed or reworded by the writer. A reader matches it to intent with `normalise_clause(entry["proves_clause"]) == normalise_clause(intent["clause"])` (ticket 21's normaliser, conflict 2 of the G3 note). The schema does not normalise or cross-check. |
| `code_file` | string, minLength 1 | Repo-root-relative POSIX path of the code file the entry exercises. Existence is judged by ACD-2500c-1-i, not the schema. |
| `to_be_created` | boolean | True when `code_file` does not exist yet. Absent means false. |
| `convention_test_file` | string, minLength 1 | The neighbouring existing test file cited as the convention for a to-be-created file. |

Record-level provenance (new top-level properties; the root has `additionalProperties: false`, so they must be declared there). Both are plain types, with no `oneOf` and no null branch, so jsonschema names the path (`test_design_authorship.step`) as it does for `test_intent`:
- `test_design_authorship`: object, `required: [step, date]`, `additionalProperties: false`. `step` is a string, minLength 1: the code-aware agent id (working value `test-designer`, the user still confirms it in ACD-2500d-5; the schema does not enumerate agent ids). `date` is `YYYY-MM-DD`. Trap: an unquoted `date: 2026-10-14` loads as a `datetime.date`, and `type: string` would reject it. Default (the `created` precedent): declare `date` with no `type`, `pattern: "^\\d{4}-\\d{2}-\\d{2}$"` (jsonschema applies `pattern` to strings only, so a native date passes) plus `not: {type: [null, boolean, integer, number, array, object]}` so numbers and containers still fail. The mark is absent or valid; null is rejected; absent means legacy.
- `test_design_opened_files`: array of strings, items minLength 1, NO minItems. An empty list is schema-valid on purpose: ACD-2500c-1-i reports it as "not grounded". Repo-root-relative POSIX is a writer rule and a c-1-i check, not a schema rule.
