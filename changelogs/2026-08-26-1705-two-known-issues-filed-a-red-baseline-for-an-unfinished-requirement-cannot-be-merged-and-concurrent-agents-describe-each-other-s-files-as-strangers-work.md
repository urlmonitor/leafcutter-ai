description: "The first entry concerns two mechanisms that each look correct and disagree. The acceptance-criteria enforcement plugin downgrades a failing test to an expected failure when the requirement it covers is not yet finished, and its own documentation states that this masking is the default and opting out is the exception. The continuous-integration test job sets the opt-out variable for the whole run, and that job is a required check whose configuration comment states the intent plainly: a pull request carrying a failing test fails the check and cannot merge. The consequence is that the plugin's default never applies in the one place a test outcome decides anything. This was measured rather than inferred, on one file at one commit: run locally with no flag it reports three expected failures and exits zero, and the identical file in the pipeline reports three real failures and turns the required check red. Two consequences follow. A deliberately-failing test written before its fix exists cannot reach the main branch at all, which is what the acceptance-criteria-driven practice asks authors to produce; sixteen such tests across eight files were observed in this state on one pull request, every one passing locally and every one failing in the pipeline. And where the masking does apply, it inverts the local signal, because a masked run exits zero and the only indication that genuinely broken behaviour is being hidden is a summary line competing with several thousand other results. The entry is careful to say that the strict setting is a good decision and does not argue against it. The defect is that both mechanisms are maintained while only one can ever apply, so the plugin carries masking logic, a reporter and two test files for a behaviour its only blocking consumer switches off. The fix direction leads with making the baseline explicit through a strict expected-failure marker, which is honest in both environments because the test framework handles it before the plugin sees a failure, and which retires itself on the day the defect is fixed because the unexpected pass then fails the run and forces the marker's removal. It notes that this cannot manufacture false evidence of completion, since the proof-of-done gate already refuses to count an expected failure. Only then does it suggest deciding the plugin's fate on the resulting numbers. The second entry records that four authoring agents dispatched in parallel into one shared worktree each inspected the repository status, saw untracked files they had not written, and reported them in their sign-offs as unrelated pre-existing work from other parallel sessions, recommending they be left alone. Every file so described had been written minutes earlier by a sibling in the same dispatch, and all four reached the same conclusion independently. The entry argues this is a systematic misreading rather than an avoidable mistake, because the inference is locally sound for an agent whose instructions never mention that a peer might be writing beside it. Three costs are named in ascending order: the operator receives four individually credible contamination reports about a clean tree, the staging advice is wrong in a way that looks careful and would drop the sibling work the same drive produced, and the failure mode is one step from destruction, since an agent that decided stray untracked files should be cleaned up rather than preserved would delete peer output that is unrecoverable. Nothing observed went that far and no work was lost, and the entry states explicitly that the reason is that all four agents chose the conservative branch, not that anything prevented the other one. The fix direction is to tell a dispatched agent that it may have company and that files it did not write are peers' work, with the narrow mechanical form being that an agent stages by explicit path and reports only on paths it wrote, which removes the need for the agent to reason about ownership at all. It warns against the tempting alternative of having each agent work out who wrote what, since the available evidence cannot answer that and confident guessing is what produced the reports in the first place."
