# EPIC-OneDurableLogRootForEveryWorkspace

## Goal

Make every per-drive workspace write its operational logs (feedback, agent telemetry,
knowledge emissions) to the one enduring log root its main install recorded at build
time, so records survive worktree removal and every drive's reports are readable from
one place (parent AC INF-500d-4).

This epic assembles 7 ticket(s) from an explicit connected-set id list: INF-500d-4-iii, INF-500d-4-i, INF-500d-4-iv, INF-500d-4-v, INF-500d-4-vi, INF-500d-4-vii, INF-500d-4-viii. Generated by build_epic_from_ids — the id set is taken as authoritative (no subtree re-derivation). INF-500d-4-ii is already done and is excluded.
