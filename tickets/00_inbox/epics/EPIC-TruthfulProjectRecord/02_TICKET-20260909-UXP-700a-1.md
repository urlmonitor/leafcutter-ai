## Acceptance Criteria

```gherkin
Given a project that has never used the tooling and holds no project record of any kind,
When the tooling is installed into that project,
Then a record is written into that project with a place for each artifact type the tooling
  supports (journeys, example data, screens), each of those places present and empty,
And a store index is written that declares zero artifacts and holds an entry for every
  derived lookup the index maintains, each of those entries empty,
And every input the checker reads before it begins checking is written into that project,
  so the checker reaches a stated verdict without an unhandled failure,
And an introduction is written into that project stating that the record is empty, naming
  each artifact type and where it lives, and naming the first thing a person should author.
```
