# Duplicate detection rejects AC whose criteria duplicates an existing pattern

## Actor / Goal

As the leafcutter-ai system, I want to implement AC `ACS-500c-3` — Duplicate detection rejects AC whose criteria duplicates an existing pattern — so that the acceptance criterion is satisfied.

## Context

This ticket was generated from AC store entry `ACS-500c-3`. Component: `ac-store`. Assigned agent: `python-coder`. Estimated complexity: `L`.

## Acceptance Criteria

```gherkin
Given the AC store contains a pattern AC (id: "PTN-001") defining
  "paginated-collection" behavior with criteria covering page size,
  next/previous navigation, and total count display,
When an authoring agent attempts to create a new AC whose criteria field
  restates the same pagination behavior with different entity nouns
  (e.g. "orders" instead of the pattern's placeholder),
Then the validation step flags the new AC as a likely duplicate of PTN-001,
And the agent is prompted to use implements_pattern: "PTN-001"
  with pattern_bindings instead of creating a standalone AC,
And the duplicate AC is NOT written to the store.
```
