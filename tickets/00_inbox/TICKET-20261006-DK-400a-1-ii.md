## Actor / Goal

## Implementation Notes

```yaml
- Gap accounting for the request itself (the split subject) is decided when the split's
  outcome is known, never at detection. Approved -> no unsupported or ambiguous gap
  observation for the request itself. Trigger jev_none rejected, too few parts or
  an abandoned proposal (DK-400c-3, DK-400c-1-ii) -> exactly today's unsupported observation
  (same gap_key, gap_type and fields, fallback_outcome blocked) and capability_gap_recorded
  true. Trigger ambiguous rejected, too few parts or abandoned -> no gap while today's
  clarification question is open; today's ambiguous observation only if that clarification
  ends unresolved (the person cannot be asked, or intent.max_clarifications is reached),
  exactly as today. bundled_accepted or mid_run -> never a gap for the request itself.
  Run cancelled before the gate answer -> no gap for the request itself (mock-data
  v6 invariant on capability_gap_recorded).
- 'The host.decompose_goal operation records no host_only gap observation: it is the
  split''s coordination step, not a build opportunity, and recording it would list
  the subject''s goal tokens as a build opportunity.'
- '''No capability-gap record for the request itself'' (the BA''s final-gate wording)
  scopes the rule: observations from a part''s own work (its research, options or
  synthesis host operations, a no_match of a part''s child) are recorded exactly as
  a stand-alone run of that part would record them, attributed to the part''s request
  and never to the split subject.'
- A single question no capability can meet produces today's gap observation unchanged
  (gap_key, gap_type, normalized_need, fallback_outcome), so occurrence counts across
  runs stay comparable before and after this feature.
- 'Tests enable splitting explicitly: split.enabled true through a config override
  (false only where a test compares with the off switch). None relies on the shipped
  default, which stays false until E3 merges (dec-9925ebf1895222f4, see DK-400a-1).
  A test asserting that no split starts must run with splitting on, or it passes for
  the wrong reason.'
```

```python
"""
MODULE: tests.kernel.split.test_dk_400a_1_ii
GOAL: Prove an approved split leaves no capability-gap record for the request itself while a
    single request no capability can meet still records today's gap (AC DK-400a-1-ii).
BUSINESS CONTEXT: ADR-053: the gap list is a build backlog. A request the kernel split and the
    person approved was not a missing capability, so its goal must not rank as a build
    opportunity, while a real gap keeps counting exactly as it does today.
ARCHITECTURE: Real KernelService through the scenario rig and the shipped CLI main(); only Jev is
    scripted. Run A is the reviewed Mock Data goal (support_400c), run B a single request. Every
    test enables splitting through a config override. RED until the gap for the split subject
    is decided at the split outcome instead of at detection.
"""

from __future__ import annotations

import asyncio
import contextlib
import io
import json
from typing import Any

from kernel.adapters.cli import main
from kernel.contracts import Actor, ActorKind, RunEnvelope, RunStatus, TaskInput, schema_ids
from tests.kernel.helpers import make_scope
from tests.kernel.integration.scenario_support import (
    FakeHostResponder,
    answer_human,
    options_response,
)
from tests.kernel.split.support_400c import GOAL, PROPOSED, ProposalCase

REQUEST_B = "Write release notes for the last ten merged pull requests"


def observations(case: ProposalCase) -> list[dict[str, Any]]:
    """Return the raw gaps/observations.jsonl rows of the run root, read from disk."""
    path = case.run_root / "gaps" / "observations.jsonl"
    if not path.exists():
        return []
    return [json.loads(ln) for ln in path.read_text(encoding="utf-8").splitlines() if ln.strip()]


def mentions(row: dict[str, Any], text: str) -> bool:
    """Return True when the observation is about `text` (its goal contains it)."""
    flat = " ".join(text.lower().split())
    return flat in " ".join(str(row.get("goal", "")).lower().split())


class SplitGapCase(ProposalCase):
    """Runs A (approved split) and B (single unsupported request) over one run root."""

    def request_b(self) -> TaskInput:
        """Return run B's single request."""
        return TaskInput(goal=REQUEST_B, caller=Actor(id="tester", kind=ActorKind.HOST),
                         scope=make_scope(self.repo))

    async def run_a(self) -> RunEnvelope:
        """Run A: turned away by routing, split offered, approved, parts scripted to settle."""
        self.arrange()
        _, _, gate = await self.propose()
        self.assertEqual(gate.status, RunStatus.WAITING_HUMAN)
        self.route_choice = "decision"  # the parts are real decisions the router accepts
        done = await self.service().resume_run(
            gate.run_id, answer_human(gate, {"choice_id": "approve"}))
        responder = FakeHostResponder({schema_ids.OPTIONS: options_response("primary")})
        for _ in range(12):  # bounded: answer whatever the parts ask of the host
            if done.status != RunStatus.WAITING_HOST:
                break
            try:
                done = await self.service().resume_run(done.run_id, responder.answer(done))
            except KeyError:
                break
        return done

    async def run_b(self, **split: Any) -> RunEnvelope:
        """Run B: the single request no capability can meet."""
        self.arrange(**split)
        run = await self.service().start_run(self.request_b())
        if run.status == RunStatus.WAITING_HOST:  # a split is offered: the host sees one part
            one_part = [{"id": "p1", "text": REQUEST_B, "covers": REQUEST_B, "depends_on": [],
                         "child_capability": "decision"}]
            run = await self.service().resume_run(run.run_id, self.host_answer(run, one_part))
        return run


class TestApprovedSplitRecordsNoGap(SplitGapCase):
    """The split subject is not a gap once the split is approved."""

    async def test_approved_split_records_no_gap_for_its_subject(self) -> None:
        # covers: DK-400a-1-ii
        # angle: criterion
        """AC-2, AC-4: no observation for the root goal; its goal is no build opportunity."""
        done = await self.run_a()
        self.assertNotEqual(done.status, RunStatus.FAILED)
        rows = observations(self)
        # The approval really took effect (otherwise "no gap" would hold for the wrong reason).
        (split,) = self.splits_of(await self.checkpoint_values(done.run_id))
        self.assertEqual(split.gate_answer, "approve")
        self.assertFalse(split.capability_gap_recorded)
        self.assertNotEqual(done.status, RunStatus.BLOCKED)
        self.assertEqual([r for r in rows if mentions(r, GOAL)], [])
        build = [g for g in self.service().list_gaps()
                 if g.gap_type.value in ("unsupported", "host_only")]
        self.assertEqual([g for g in build if mentions(g.model_dump(), GOAL)], [])


class TestSingleRequestKeepsToday(SplitGapCase):
    """A single unsupported request records today's gap, unchanged."""

    async def test_single_unsupported_request_records_todays_gap(self) -> None:
        # covers: DK-400a-1-ii
        # angle: criterion
        """AC-1, AC-3: one unsupported observation, equal in every stable field to splitting off."""
        on = await self.run_b()
        self.assertEqual(on.status, RunStatus.BLOCKED)
        mine = [r for r in observations(self) if mentions(r, REQUEST_B)]
        self.assertEqual(len(mine), 1)
        self.assertEqual(mine[0]["gap_type"], "unsupported")
        self.assertEqual(mine[0]["fallback_outcome"], "blocked")
        total_after_on = len(observations(self))
        off = await self.run_b(enabled=False)
        self.assertEqual(off.status, RunStatus.BLOCKED)
        self.assertEqual(len(observations(self)), total_after_on + 1)
        rows = [r for r in observations(self) if mentions(r, REQUEST_B)]
        self.assertEqual(len(rows), 2)  # one per run: nothing extra, nothing missing
        volatile = {"id", "first_seen", "last_seen", "example_run_ids", "example_trace_urls",
                    "run_id", "observed_at", "occurrence_count"}
        stripped = [{k: v for k, v in r.items() if k not in volatile and not k.endswith("_at")
                     and "run_id" not in k and "work" not in k and "trace" not in k
                     and "draft" not in k} for r in rows]
        self.assertEqual(stripped[0], stripped[1])


class TestGapListAcrossRuns(SplitGapCase):
    """The gap list over both runs counts only run B."""

    async def test_gap_list_across_runs_counts_only_run_b(self) -> None:
        # covers: DK-400a-1-ii
        # angle: reachability
        """AC-2, AC-3, AC-4: the shipped `kernel gaps` lists run B's gap, not run A's goal."""
        a = await self.run_a()
        self.assertNotEqual(a.status, RunStatus.BLOCKED)  # approved and carried on, not stranded
        b = await self.run_b()
        self.assertEqual(b.status, RunStatus.BLOCKED)

        def factory(**_: Any) -> Any:
            self.service()
            return self.env

        def cli(argv: list[str]) -> dict[str, Any]:
            out = io.StringIO()
            with contextlib.redirect_stdout(out):
                main(argv, environment=factory)
            return json.loads([ln for ln in out.getvalue().splitlines() if ln.strip()][-1])

        document = await asyncio.to_thread(cli, ["gaps", "--json"])
        self.assertEqual([g for g in document["gaps"] if a.run_id in g["example_run_ids"]
                          and mentions(g, GOAL)], [])
        self.assertEqual([g for g in document["gaps"] if mentions(g, GOAL)], [])
        from_b = [g for g in document["gaps"] if b.run_id in g["example_run_ids"]]
        self.assertEqual(len(from_b), 1)
        self.assertTrue(from_b[0]["build_opportunity"])
        self.assertEqual(document["total"], len(self.service().list_gaps()))


class TestDecomposeAnswerRecordsNoHostGap(SplitGapCase):
    """Accepting the host's decomposition appends no host_only observation."""

    async def test_decompose_goal_answer_records_no_host_only_gap(self) -> None:
        # covers: DK-400a-1-ii
        # angle: seam
        """The real host answer (goal_decomposition.v1) is consumed; observations stay as before."""
        self.arrange()
        waiting = await self.service().start_run(self.goal_task())
        before = observations(self)
        after = await self.service().resume_run(waiting.run_id, self.host_answer(waiting, PROPOSED))
        self.assertEqual(after.status, RunStatus.WAITING_HUMAN)  # the gate: answer was accepted
        self.assertEqual(observations(self), before)
        self.assertEqual([r for r in observations(self) if r.get("gap_type") == "host_only"], [])
        # No gap for the subject while the gate is open either (decided at the outcome).
        self.assertEqual([r for r in observations(self) if mentions(r, GOAL)], [])
```
