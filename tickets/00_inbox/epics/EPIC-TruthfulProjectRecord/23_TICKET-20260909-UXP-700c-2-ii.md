## Acceptance Criteria

```gherkin
Given a journey that the last check reported as behind,
When that check completes,
Then a mark is written into the journey record stating that it is behind and what it was
  last confirmed against,
And that mark is written to disk in the record itself, so any surface that reads the record
  can show it without re-running the check,
And a later check that finds the journey current removes the mark,
And no mark is written for a journey the check did not examine.
```

- [x] AC-2: that mark is written to disk in the record itself, so any surface that reads the record
- [x] AC-3: a later check that finds the journey current removes the mark
- [x] AC-4: no mark is written for a journey the check did not examine.
