## Repository Structure & Git Sync

This repo is the **development workspace** for the leafcutter-ai package.

| Directory | Purpose |
|-----------|---------|
| `leafcutter-ai/` | **Package source** — synced with `origin` (`git@github.com-urlmonitor:urlmonitor/leafcutter-ai.git`) via `git subtree`. All package development happens here. |
| Root level (`scripts/`, `tickets/`, `.claude/`, etc.) | **Consumer/build outputs** — generated by `build.py`. Not synced with origin. |

### Git subtree commands

```bash
# Pull latest from origin into leafcutter-ai/
git subtree pull --prefix=leafcutter-ai origin main --squash -m "subtree: pull origin/main"

# Push leafcutter-ai/ changes to origin
git subtree push --prefix=leafcutter-ai origin main
```

## Glossary

Project jargon and terminology is tracked at [docs/glossary.md](docs/glossary.md).

Consult it for project-specific terms when reading code or docs.

- **To populate from scratch**: run `/glossary-bootstrap` (once after initial install
  or after a major codebase merge).
- **Ongoing additions**: the `check-glossary-coverage` pre-commit hook detects novel
  terms in staged files and dispatches the `glossary-triage` agent automatically.
- **Do NOT hand-edit to add entries** — always use the triage flow so the blacklist
  stays consistent. Manual edits are only for correcting existing entries.
