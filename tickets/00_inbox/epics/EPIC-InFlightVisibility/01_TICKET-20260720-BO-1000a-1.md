# Every non-error finalize step emits a start-of-step progress line on the success path

## Actor / Goal

As the leafcutter-ai system, I want to implement AC `BO-1000a-1` — Every non-error finalize step emits a start-of-step progress line on the success path — so that the acceptance criterion is satisfied.

## Context

This ticket was generated from AC store entry `BO-1000a-1`. Component: `build-orchestration`. Assigned agent: `python-coder`. Estimated complexity: `M`. Complexity: `medium`.

## Acceptance Criteria

```gherkin
Given the finalize-feature workflow is run to completion with no step
  encountering an error,
When each numbered step of the sequence begins its work (baseline capture,
  open PR, merge the mainline in, run tests, close tickets and source ACs,
  merge the PR, sync the local mainline, report untracked failures, remove
  the worktree),
Then a human-readable progress line is emitted at the start of that step, on
  the success path, before the step's work is dispatched — naming the step,
  its position in the form "Step X of N", and what the step is about to do,
And such a start-of-step line is emitted for every non-error step, not only
  for steps that enter an error or malformed-result branch.
```

- [ ] AC-1: a human-readable progress line is emitted at the start of that step, on
- [ ] AC-2: such a start-of-step line is emitted for every non-error step, not only
