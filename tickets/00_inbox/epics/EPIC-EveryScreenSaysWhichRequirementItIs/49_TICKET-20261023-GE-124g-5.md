## Implementation Notes

```yaml
- 'Author under docs/reference/ with check_doc_frontmatter-compliant frontmatter (title,
  type: reference, status, created, last_updated, components, description) and stay
  within the check_doc_length budget.'
- 'THE FOUR EVIDENCE KINDS MAP TO FOUR REAL STORE FIELDS AND MUST BE NAMED AS SUCH:
  declared_by (component-level declaration), pinned_by (element pin), the design-to-page
  link (GE-124f-1''s data-screen chain record), and covered_by (a covering test).
  Cross-reference docs/reference/ac-schema.md rather than restating the field definitions,
  and make sure the two documents agree — GE-124g-1 adds two of these four fields
  to the schema, so this doc and that schema change land together or the reference
  describes fields that do not exist.'
- REACHABILITY IS THE CLAUSE THAT DECIDES WHETHER THIS WORKS, AND IT IS AN OBLIGATION
  ON THE CHECKS, NOT ON THE DOC. Each of the three traceability checks — the GE-111
  reconciliation check, GE-117's declaration check, and GE-124's frontend declaration
  check — must carry a link to this reference in its module docstring or its help
  output. A standing rule nobody encounters is a rule that gets rediscovered as a
  defect, and the binding surfaces are the three checks themselves, which is where
  the author of a fourth one will be looking. The test contract asserts this from
  the checks' side.
- THE FOUR BLOCKED PLACES MUST BE DESCRIBED IN TERMS OF WHAT BLOCKING LOOKS LIKE —
  a rejected covered_by write, a done assessment that stays unfinished, a report axis
  that is never summed, an existence-only test that is not accepted — with a pointer
  to the AC that owns each. Naming the places without naming their mechanism leaves
  a future author agreeing with the rule and unable to apply it.
- 'STATE THE GE-124d BOUNDARY EXPLICITLY: the warn tier and the per-item opt-out apply
  ONLY to whether a file must declare, and never to what a declaration is worth. This
  is the boundary an author looking for an escape will test first.'
- 'WORDING THE DOC MUST NOT DRIFT FROM, per the PO: presence, not proof. On screen,
  not correct. A signpost, not a result. The one-sentence rule is required content
  — a reference doc a reader cannot quote back is a reference doc that does not travel.'
- change_target stays `code` under the L0's tree-wide instruction; the deliverable
  is the reference document.
```
