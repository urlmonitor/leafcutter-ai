# The in-flight step is identifiable from the start line even when its sub-agent errors

## Actor / Goal

As the leafcutter-ai system, I want to implement AC `BO-1000a-1-i` — The in-flight step is identifiable from the start line even when its sub-agent errors — so that the acceptance criterion is satisfied.

## Context

This ticket was generated from AC store entry `BO-1000a-1-i`. Component: `build-orchestration`. Assigned agent: `python-coder`. Estimated complexity: `S`. Complexity: `low`.

## Acceptance Criteria

```gherkin
Given a step's sub-agent returns an error or a malformed result partway
  through the finalize run,
When the failure surfaces,
Then the start-of-step progress line for that step was already emitted before
  the failure occurred, so the step that was in flight at the moment of
  failure is identifiable from the progress output alone,
And identifying the in-flight step does not depend on the error branch
  emitting its own separate diagnostic line.
```

- [ ] AC-1: the start-of-step progress line for that step was already emitted before
- [ ] AC-2: identifying the in-flight step does not depend on the error branch
