# 05: Create .github/DISCUSSION_TEMPLATE/ files on leafcutter-ai

## Goal

In order to structure GitHub Discussions for the `leafcutter-ai` repo so that "How do I...?" questions and open-ended ideas have guided forms, we need to author `how-to.yml` and `ideas.yml` Discussion templates.

## Context

Stub generated by create-epic. Harden with create-ticket (depth 3).

All changes are on the `urlmonitor/leafcutter-ai` upstream repo. This ticket can run in parallel with 01–04, 06, 07, 08.

Note: GitHub Discussions must be enabled on the repo before these templates take effect. If Discussions is not yet enabled, enabling it is a prerequisite step for this ticket (can be done via the repo Settings → Features panel — no code change needed).

`how-to.yml` fields: what are you trying to do, what have you tried.
`ideas.yml` fields: description, motivation, prior art.

## Acceptance Criteria

```gherkin
Given GitHub Discussions is enabled on leafcutter-ai
When a user starts a new Discussion
Then they can choose "How do I...?" category with guided fields: what-are-you-trying-to-do, what-have-you-tried
And they can choose "Ideas" category with guided fields: description, motivation, prior-art
```
