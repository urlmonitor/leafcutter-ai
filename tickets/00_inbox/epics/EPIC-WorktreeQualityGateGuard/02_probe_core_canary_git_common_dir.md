# 02: Probe Core + Canary + Git-Common-Dir Resolution

## Goal
Implement the four-check orchestrator probe (verify_precommit_active.py) that verifies pre-commit hooks fire, the manual-stage-only canary hook (precommit_canary.py), git-common-dir resolution for locating the main tree, and integrate the canary into the generated pre-commit config via build_precommit.

## Context
Stub generated by create-epic. This ticket implements the core execution-proof machinery:
- verify_precommit_active.py: checks A (binary), B (config), C (git_hook), D (canary token)
- precommit_canary.py: emits PRECOMMIT_CANARY_OK, registered manual-stage-only
- git-common-dir resolution: maps worktree → main-tree .leafcutter location
- Templates mirrors for ADR-001 self-hosting parity
- build_precommit must emit the canary into the generated config

This is the single producer consumed by all gates (BO-1700b/d families).
