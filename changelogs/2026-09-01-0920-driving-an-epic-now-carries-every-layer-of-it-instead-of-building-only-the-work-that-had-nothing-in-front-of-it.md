description: "Driving a thirty-seven piece body of work built seventeen and left twenty untouched, and the twenty were exactly those that had a prerequisite. The question of what was ready was asked once, at the beginning, at the only moment when the answer could not include anything that had to wait. The run now re-asks as pieces finish, so a chain four deep is carried to the end by one start rather than needing a separate start for each layer, and nothing about the run says how many layers remain. Widening that loop is most of the change; the rest is the care it turned out to need, because a loop that keeps asking has to be able to disbelieve the answers. Six separate defects were found and fixed while building it, and every one was the same mistake in a different place: taking what the planning step reported as fact. Work finished in an earlier session could never satisfy anything, because the run demanded a verdict of its own for a prerequisite it had not driven and never would — which made resuming a part-finished body of work impossible whenever one piece depended on another. Work already recorded finished was offered again and built a second time, inflating the tally past the number of pieces that existed. Work added to the folder after the run began was picked up and built, contradicting a settled decision that such work must be reported and left alone, because absorbing it gives a run no stopping point. A repair for that last one admitted anything that merely claimed a link to work already in the set, which is what a newly added piece normally looks like, so it admitted most of the thing it was meant to exclude. A reply that offered an empty container rather than an empty list satisfied neither the check for offered work nor the check for an empty answer, and sent the run round forever with no limit and no error. And the list of already-finished work was itself believed without being read back, leaving one unchecked input inside the very guard whose purpose is that there are none. Each is now checked against evidence the run gathers itself: outcomes it watched, or records it opens and reads. The run also says when it could not establish what it started with, rather than degrading quietly. Nineteen existing tests broke on the widened loop and were repaired without weakening a single assertion — they cover four settled criteria and are what caught the worst of these defects, so they were treated as the evidence they are rather than as obstacles."
