## Implementation Notes

```yaml
- THE SUBJECT SET IS git's STAGED CHANGE LIST — `git diff --cached --name-only --diff-filter=ACMR`
  including renames via -M so the file's current path is the one examined. Never a
  repository walk, never a glob over the working tree. This mirrors the established
  staged-files-only scoping in check_ac_circular_deps, check_ac_schema Phase 2, GE-111c-1
  and ACS-400e-2; an unexamined convention here is one refactor away from a whole-tree
  scan that fails on the entire existing frontend.
- NOT EXAMINED IS A THIRD STATE, NOT A PASS AND NOT A FINDING. An unstaged file must
  appear in NO output collection — not in findings, not in pass records, not in any
  count the run produces. If the check emits a structured report, an unstaged file
  must be absent from it entirely; being present with a 'skipped' or 'clean' marker
  reintroduces exactly the reading this scenario forbids.
- 'THE PASS RECORD IS A RECORD, NOT A BANNER. One per examined in-scope file, naming
  the criteria declared and the number of pinned elements (mock record gf-commit-realization-badge).
  Its language is constrained by GE-124e-5 and its counting by GE-124g-3: it may say
  declared, never verified, covered or proven. Malformed pins (GE-124b-1-ii) do not
  count towards the pinned-element number.'
- AN EMPTY IN-SCOPE SET IS A PROCEED, NOT A FAILURE. A staged set containing no in-scope
  screen components exits 0 with no findings — the false-positive guard GE-117d-2
  also carries. An empty verdict set must not read as 'nothing was checked, therefore
  fail'.
- ONE DIFF-SCOPING PRINCIPLE, TWO SUBJECT TYPES. This AC and GE-124e-4 are the same
  rule; here the subject is a file path and the diff selects it directly, there the
  subject is a criterion id and needs two routes. Implement them as two applications
  of one stated principle, and do not let either grow a cutoff, an exempt list or
  a backfill counter — scenario 3 IS the backfill mechanism.
- Must handle errors gracefully per the project error handling policy; the partially-unreadable
  staged set is GE-124c-3-i's contract.
```
