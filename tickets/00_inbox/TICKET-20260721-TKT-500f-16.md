## Acceptance Criteria

```gherkin
Given a leaf AC whose components LIST already contains one or more kebab
  (non-graph-id) values — for example ["build-orchestration"] or a mixed list
  ["ticket_creation_pipeline", "build-orchestration"],
When a ticket is generated from that AC by generate_ticket_from_ac.py
  (_build_components_list),
Then every element of the generated ticket's components LIST is the
  components.json underscore graph id for that value (for example
  build-orchestration is normalised to build_orchestration),
And no kebab element passes through unnormalised — the generated LIST contains no
  element still bearing a hyphen when an underscore graph id exists for it,
And elements that were already valid underscore graph ids are preserved unchanged
  and are not duplicated.
```
