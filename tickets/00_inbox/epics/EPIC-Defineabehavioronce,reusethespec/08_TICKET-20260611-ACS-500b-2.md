## Acceptance Criteria

```gherkin
Given a page uses the "sortable-table" pattern via implements_pattern,
And the page needs non-standard sorting behavior on one column
  (e.g. "status column sorts by priority order, not alphabetical"),
When the deviation is specified,
Then it is written as a separate AC file in the same feature folder,
And that deviation AC has its own id, criteria with Given/When/Then,
  and depends_on referencing the consuming AC,
And the deviation AC does NOT contain an implements_pattern field,
And the original consuming AC's pattern_bindings remain unchanged
  (the pattern itself is never partially overridden inline).
```
