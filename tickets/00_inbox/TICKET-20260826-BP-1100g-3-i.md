## Acceptance Criteria

```gherkin
Given two failing tests that differ in exactly one respect: the first carries a
    tag naming the kind of proof it was written to give, and the second carries
    none,
  And both carry the same existing coverage tag for the same piece of work,
When the run's outcome is decided,
Then both tests are treated identically, and the run's outcome is the one it
  would have had if neither tag were present,
  And the existing coverage tag alone continues to decide which failing tests are
    treated as blocking,
  And a piece of work whose tests all carry kind tags is no closer to being
    counted done than the same work with the tags removed,
  And removing every kind tag from the suite changes no run outcome and no
    completion decision anywhere.
```
