# Someone wiring a new guard into the editor's own tool calls, following only the written instructions, ends up with one the run reports as declared and examined — and the step they skip is the one the run names

## Actor / Goal

As the leafcutter-ai system, I want to implement AC `GE-129a-5` — Someone wiring a new guard into the editor's own tool calls, following only the written instructions, ends up with one the run reports as declared and examined — and the step they skip is the one the run names — so that the acceptance criterion is satisfied.

## Context

This ticket was generated from AC store entry `GE-129a-5`. Component: `guardrail-engine`. Assigned agent: `documentation-expert`. Estimated complexity: `M`. Complexity: `medium`.

## Acceptance Criteria

```gherkin
Given the written instructions a person follows to add a guard that runs in response to the
  editor's own tool calls,
When someone follows those instructions from beginning to end, consulting nothing else,
Then the guard they end up with is reported by the liveness run as carrying a declaration
  tied to the entry that runs it, and as having been examined, rather than as carrying no
  declaration,
And given the same instructions are followed again with the step that produces the
  declaration left out, and nothing else done differently,
Then the guard that results is reported as carrying no declaration, naming it — so the two
  walkthroughs differ in the run's output in exactly the way the omitted step predicts,
And the instructions state, in the same words the run reports in, what an author must
  declare — one known-bad input, the observable rejection it must produce, and the ground
  for the alternative when no known-bad input is meaningful —
And they state which of the four states a guard's examination can end in mean that the
  guard is not counted among the things keeping the work safe,
And they say that the rejection an author declares has to be one the kind of tool call the
  guard is wired at is able to produce,
And they are reachable from where a person is already reading when they wire a guard to a
  tool-call event, rather than only from a record about guards in general.
```
