# Code that no way of running the product can reach cannot be marked done, however many tests pass

## Actor / Goal

As the leafcutter-ai system, I want to implement AC `BO-2900a-3` — Code that no way of running the product can reach cannot be marked done, however many tests pass — so that the acceptance criterion is satisfied.

## Context

## Acceptance Criteria

```gherkin
Given an acceptance criterion whose implementing code lives in a unit that exposes
  no runtime way in of its own,
  And no unit that does expose a runtime way in reaches that code,
  And no automation runs that unit as a program,
  And the criterion's proof-of-done test is present, executes the code, and passes,
When the criterion is evaluated for eligibility to be marked done,
Then the criterion is rejected as not eligible,
  And the rejection states that no way of running the product reaches the code, and
    names the unit,
  And adding a further passing test over the same code leaves the verdict unchanged,
  And the verdict changes only when the code is given a way in, or when an exemption
    for that unit is recorded.
```

- [x] AC-1: no unit that does expose a runtime way in reaches that code
- [x] AC-2: no automation runs that unit as a program
- [x] AC-3: the criterion's proof-of-done test is present, executes the code, and passes
- [x] AC-4: the criterion is rejected as not eligible
- [x] AC-5: the rejection states that no way of running the product reaches the code, and
- [x] AC-6: adding a further passing test over the same code leaves the verdict unchanged
- [x] AC-7: the verdict changes only when the code is given a way in, or when an exemption
