## Acceptance Criteria

```gherkin
Given a check has refused a commit in a workspace and its report names a
  remedy,
And a second workspace is live at the same time,
When the named remedy is carried out from inside the refused workspace,
Then the refusal it was offered for no longer occurs when the check is re-run
  in that workspace,
And the shared install tree is byte-identical before and after the remedy,
And the second workspace's supporting material is byte-identical before and
  after the remedy.
```

## Implementation Notes

```yaml
- 'A remedy MUST be named. This record is not satisfiable by deleting the remedy line
  from the refusal: the first clause requires that carrying out the named remedy actually
  clears the refusal, so ''offer nothing'' fails rather than passes. Without that
  clause the safest implementation would leave the author stuck instead of safe.'
- 'The remedy currently named by both drift gates is ''Re-run build.py'' (check_output_drift
  prints ''build.py (or: python leafcutter/scripts/build.py --force)''). From inside
  a worktree that is KI-BP-016: it deploys the branch''s unmerged templates over the
  live shared install tree other sessions are reading, and it overwrites the tracked
  docs/INDEX.md. The remedy text must change in step with BO-4100b-3''s per-workspace
  material so the named command acts on the workspace''s own copy only.'
- The remedy must be executable exactly as printed, from the workspace it was printed
  in, with no argument the operator has to infer. A remedy that needs a --target-dir
  the operator has to work out is the same defect one step removed.
- Byte-identity of the shared install tree and of the second live workspace must be
  established across the remedy by recursive content hashing of each whole tree.
- Both drift gates must carry the corrected remedy; a fixed message in one and the
  KI-BP-016 message in the other still sends the operator to destroy the shared install
  half the time.
- Template and deployed copies change together and are verified in parity via the
  build.py round-trip (ADR-001).
```
