# 04: Fail-Closed Invariant + Anti-Bypass

## Goal
Enforce the fail-closed-on-self-error invariant in the probe, ensure PRE_COMMIT_ALLOW_NO_CONFIG is never set, document --no-verify bypass prevention, and guarantee canary removal on shutdown.

## Context
Stub generated by create-ticket hardening pass. This ticket enforces the safety invariants:
- BO-1700b-1: Fail-closed on probe self-error (exception, non-zero exit, timeout → FAIL, no proceed)
- BO-1700b-2: PRE_COMMIT_ALLOW_NO_CONFIG must never be set by the guard
- BO-1700b-3: --no-verify bypass is documented in commit-phase gates and discouraged
- BO-1700b-4: Canary must be removed (stages emptied or entry deleted) on shutdown

- [ ] Enforce fail-closed invariant in verify_precommit_active.py

  - Any subprocess with non-zero exit → stop at first failing check, exit non-zero
  - Timeout after 10 seconds → exit non-zero with timeout notice
  - ONLY outcome that allows proceed: exit 0 AND failing_checks == []
  - No branch allows proceed if the probe errors internally
- [ ] Assert PRE_COMMIT_ALLOW_NO_CONFIG is never set by the guard

- [ ] Implement canary removal (shutdown path)
