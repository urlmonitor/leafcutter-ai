# The Agent Contracts block is the single source both the writer reads and the verifier asserts

## Actor / Goal

As the leafcutter-ai system, I want to implement AC `BO-2200c-5` — The Agent Contracts block is the single source both the writer reads and the verifier asserts — so that the acceptance criterion is satisfied.

## Context

This ticket was generated from AC store entry `BO-2200c-5`. Component: `build-orchestration`. Assigned agent: `python-coder`. Estimated complexity: `M`. Complexity: `medium`.

## Acceptance Criteria

```gherkin
Given a generated ticket that requires documentation and carries the
  `### documentation-expert` Agent Contracts block,
When `documentation-expert` runs, it reads that same block as its Contract-Aware brief;
  and when `documentation-verifier` runs, it asserts against that same block's
  checklist of required docs and content constraints,
Then both agents draw from one block -- there is no second, separately maintained list
  of what documentation is required.
And a change to the Agent Contracts block changes both what the writer is told to
  produce and what the verifier checks, keeping brief and enforcement in lockstep.
```
