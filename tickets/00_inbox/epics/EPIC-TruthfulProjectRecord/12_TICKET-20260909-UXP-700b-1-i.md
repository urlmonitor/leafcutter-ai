## Acceptance Criteria

```gherkin
Given a record holding five journeys, one of which cannot be read because its file is
  malformed,
When the record's checker runs,
Then it names the unreadable journey,
And it states that it examined the other four,
And the outcome it reports is neither the outcome for a run that examined nothing nor the
  outcome for a run that was checked and found sound,
And it does not stop the work that triggered it on account of that single unreadable input.
```
