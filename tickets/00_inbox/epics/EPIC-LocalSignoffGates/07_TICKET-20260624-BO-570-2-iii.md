## Context

This ticket was generated from AC store entry `BO-570-2-iii`. Component: `build-orchestration`. Assigned agent: `llm-expert`. Estimated complexity: `S`.

## Acceptance Criteria

```gherkin
Given the dev-render smoke check (BO-570-2) or the python ruff check
  (BO-570-4) ran locally and passed for a ticket,
When the agent records its sign-off,
Then the sign-off captures evidence that the check actually ran and what it
  found, including:
  - which check ran (dev-render smoke check or repo-ruff check),
  - the surface or file set it was run against (the changed frontend surface,
    or the changed Python files),
  - the outcome (passed),
And an auditor reading the sign-off afterwards can tell that the check was
  genuinely executed, not merely asserted,
And a sign-off that claims a passed check WITHOUT recording this evidence is
  not acceptable for these two gates.

Given a check was skipped (no applicable files) or inconclusive
  (tooling unavailable),
When the sign-off is recorded,
Then the evidence distinguishes skipped and inconclusive from passed,
And the recorded reason makes the non-pass outcome auditable.
```
