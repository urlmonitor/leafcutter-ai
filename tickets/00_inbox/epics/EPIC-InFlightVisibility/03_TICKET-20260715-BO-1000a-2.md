## Acceptance Criteria

```gherkin
Given the finalize-feature workflow announces "Step X of N" as each step
  begins,
When the start-of-step progress lines from a single run are collected,
Then the value of N is identical in every start-of-step line within that run,
And N equals the number of steps in the finalize sequence that the workflow
  declares it will run,
And the position X advances monotonically as the run progresses, with no
  duplicated or skipped position number for the steps that actually execute.
```
