## Acceptance Criteria

```gherkin
Given a suite in which one file cannot be collected and, separately, at least
  one test in a loadable file genuinely fails its assertion,
When the suite is run with collection-error isolation enabled,
Then the loadable-but-failing test is reported as a failure
And the overall run outcome is non-passing (it reflects the genuine failure)
And isolating the uncollectable file does not cause the run to report success
  while a real failure exists among the collectable tests.
```

## Test Requirements
