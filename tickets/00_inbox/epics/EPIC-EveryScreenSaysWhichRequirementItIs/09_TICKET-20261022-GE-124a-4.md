## Acceptance Criteria

```gherkin
Given an author is adding a new screen component and has no house convention
  to copy, because the existing declaration guidance is Python-only
When the author opens the front-end declaration how-to
Then the how-to shows a complete, copyable declaration block for each of the
  five supported file shapes — `.tsx`, `.jsx`, `.vue`, `.svelte` and `.html`
And it states where the block must sit in each shape — above the first import
  for `.tsx` and `.jsx`, above the first `<template>`, `<script>` or `<style>`
  block for `.vue` and `.svelte`, above the first element for `.html`
And it shows the multi-criterion form alongside the single-criterion form
And it states which files are asked to declare and which are not, in the terms
  the check uses — an in-scope extension plus rendered markup, minus the named
  story, test and generated-file exclusions
And it names the two things a reader must NOT conclude: that declaring a
  criterion tests it, and that an element attribute can be used instead of the
  component-level block
```
