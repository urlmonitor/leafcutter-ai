## Actor / Goal

## Acceptance Criteria

```gherkin
Given the commit guardian configuration has the diff_coverage section with:
  enabled: true
  strict: true
  min_coverage_percent: 80
  coverage_xml_path: "coverage.xml"
  compare_branch: "origin/main"
  max_age_seconds: 3600
And the diff-cover binary is installed
And coverage.xml exists and was generated 600 seconds ago (within freshness window)
And the developer has staged Python files whose diff coverage against
  origin/main measures at 45% (below the 80% threshold)
When the diff-cover hook runs at pre-commit time
Then the hook exits with code 1 (blocking)
And it emits an error listing each under-covered file with its percentage
And the error states the overall diff coverage (45%) vs the threshold (80%)
And the commit is prevented
```
