# A skipped step records a skipped outcome so the per-step record has no gaps

## Actor / Goal

As the leafcutter-ai system, I want to implement AC `BO-1000b-1-i` — A skipped step records a skipped outcome so the per-step record has no gaps — so that the acceptance criterion is satisfied.

## Context

This ticket was generated from AC store entry `BO-1000b-1-i`. Component: `build-orchestration`. Assigned agent: `python-coder`. Estimated complexity: `S`. Complexity: `low`.

## Acceptance Criteria

```gherkin
Given a step is skipped because its outcome was already satisfied,
When finalize records that step's result,
Then the step's recorded outcome is "skipped" together with the reason it was
  already satisfied,
And every step in the sequence has a recorded outcome — executed or skipped —
  so the collected per-step outcome record contains no gaps.
```

- [x] AC-1: the step's recorded outcome is "skipped" together with the reason it was
- [x] AC-2: every step in the sequence has a recorded outcome — executed or skipped —
