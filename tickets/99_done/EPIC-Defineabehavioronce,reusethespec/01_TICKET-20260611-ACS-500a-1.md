## Acceptance Criteria

```gherkin
Given an AC YAML file under docs/acceptance-criteria/ with level: L2,
When its criteria field describes behavior that multiple pages or endpoints share
  (e.g. "sortable table with columns {columns}, sorted by {default_sort}"),
And its id is referenced by other ACs via the implements_pattern field,
Then that AC is the single authoritative definition of the shared behavior,
And its criteria uses named placeholders in curly braces to mark the slots
  that consuming ACs fill via pattern_bindings,
And no other AC in the store contains an equivalent criteria body
  for the same behavior (single source of truth).
```
