## Acceptance Criteria

```gherkin
Given a JavaScript workflow body that measures 1,400 lines against a permitted length of
  1,000 before the change,
When a change that only appends 3 entry lines to its decision-history block is committed,
Then the commit completes, and the file's measured length before and after is 1,400,
And when a change appends the same 3 history entry lines and also adds 1 code line,
Then the commit does not complete, and the outcome states a length before of 1,400 and a
  length after of 1,401,
And given a Python file that measures 399 lines against a permitted length of 400,
When a change appends 20 entry lines to its decision-history block and nothing else,
Then the commit completes, and the file is not reported as having crossed its limit.
```

- [ ] AC-3: the commit does not complete, and the outcome states a length before of 1,400 and a
- [ ] AC-4: given a Python file that measures 399 lines against a permitted length of 400
- [ ] AC-5: the commit completes, and the file is not reported as having crossed its limit.
