# Reference Documentation Index

An orientation page for `docs/reference/`: one accurate line per file, grouped by
subject, so a reader can find the right lookup page without opening each one.

---

## Relationship to `docs/INDEX.md`

`docs/INDEX.md` is auto-generated by `build.py`'s doc-index phase from each file's
frontmatter `description:` field (falling back to the `title:` when `description` is
absent). It is complete and always current, but it is a flat, mechanically-produced
list — it cannot group related pages or say more about a page than its own
frontmatter already says.

This file is hand-written and does something the generated index does not: it groups
the 22 files in this directory by subject, and gives each one a one-line description
written after actually reading the page (not copied from a possibly-generic
`description:` field). **Neither file supersedes the other** — do not delete this one
as "redundant with `docs/INDEX.md`". If a page's frontmatter `description:` improves,
update `docs/INDEX.md` will regenerate automatically; update the corresponding line
below by hand.
