## Context

## Acceptance Criteria

```gherkin
Given an agent registry where agent "python-coder" lists "sql-coder"
  in its spawned_by array
And agent "sql-coder" has "python-coder" in its spawn_allowlist
But the intended spawn relationship is incorrect (sql-coder should
  not spawn python-coder in the current architecture)
When the build validates the registry for spawn-graph consistency
Then it checks every spawned_by entry for agent A referencing agent B
  against agent B's spawn_allowlist
And it checks every spawn_allowlist entry for agent B listing agent A
  against agent A's spawned_by
And if agent A's spawned_by lists agent B but agent B's spawn_allowlist
  does NOT include agent A, validation fails with:
  "asymmetric spawn: A.spawned_by includes B, but B.spawn_allowlist
   does not include A"
And if agent B's spawn_allowlist lists agent A but agent A's spawned_by
  does NOT include agent B, validation fails with:
  "asymmetric spawn: B.spawn_allowlist includes A, but A.spawned_by
   does not include B"
And the error names both agents involved in the asymmetry
```
