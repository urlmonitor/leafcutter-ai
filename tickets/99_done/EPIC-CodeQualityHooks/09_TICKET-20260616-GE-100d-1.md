## Acceptance Criteria

```gherkin
Given the commit guardian configuration has the diff_coverage section with:
  enabled: true
  compare_branch: "origin/main"
And the diff-cover binary is installed
And coverage.xml exists and is fresh
And the git remote "origin" does not have a "main" branch
  (e.g. the remote uses "master" or the remote is unreachable)
But the local branch "main" exists
When the diff-cover hook runs at pre-commit time
Then the hook falls back to comparing against the local "main" branch
And the coverage check proceeds using "main" as the comparison base

---

And neither "origin/main" nor a local "main" branch exists
When the diff-cover hook runs at pre-commit time
Then the hook falls back to comparing against "HEAD~1"
And the coverage check proceeds using the previous commit as the base
```
