# Two projects in the same folder never share or collide on a workspace

## Actor / Goal

As the leafcutter-ai system, I want to implement AC `BO-4300b-2-i` — Two projects in the same folder never share or collide on a workspace — so that the acceptance criterion is satisfied.

## Context

This ticket was generated from AC store entry `BO-4300b-2-i`. Component: `build-orchestration`. Assigned agent: `python-coder`. Estimated complexity: `S`. Complexity: `low`.

## Acceptance Criteria

```gherkin
Given two projects, "shop" and "blog", that each installed these tools, sit side
  by side in the same parent folder,
When a workspace for work named "alpha" is requested in shop, and then a
  workspace for work named "alpha" is requested in blog,
Then two distinct workspaces exist, each a copy of its own project,
And shop's "alpha" workspace is identical before and after blog's request,
And asking shop where its "alpha" workspace is returns shop's, and asking blog
  returns blog's, never the other project's.
```

- [ ] AC-1: two distinct workspaces exist, each a copy of its own project
- [ ] AC-2: shop's "alpha" workspace is identical before and after blog's request
- [ ] AC-3: asking shop where its "alpha" workspace is returns shop's, and asking blog
