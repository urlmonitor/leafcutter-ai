## Acceptance Criteria

  and its frontmatter declares files_touched: ["scripts/build_phases.py"] with
  no out_of_scope entries,

  source file that was changed but not declared in files_touched or out_of_scope
And the flag is raised at the pre-done point (before the ticket reaches
  status: done), not only after the fact
And a source file is one with an executable/source extension (.py, .sql, .ts,
  .tsx, .js); a real diff containing such a file absent from the declared scope
  is what triggers the flag
