## Implementation Notes

```yaml
- '''Reachable from the shared main line'' must be decided by patch content, not by
  commit identity. After a squash merge the pre-squash SHAs are still absent from
  main''s history while their diffs are on it, so identity-based reachability reports
  every squash-merged workspace as holding work -- and this repository squash-merges.
  templates/workflows/close-worktree.md already records this reasoning and the manual
  verification that forced it in TICKET-20260513; that reasoning must survive into
  the computed verdict.'
- Ignored files must be excluded using the project's own ignore rules as git resolves
  them, never a hard-coded list of cache directory names. A name list goes stale the
  first time a tool writes somewhere new, and every workspace then reads as holding
  work.
- The holds-nothing verdict must be reachable in practice. An implementation on which
  no realistic finished workspace ever earns it satisfies BO-4100c-1 in full and defeats
  the accumulation half of BO-4100c entirely, and that failure is invisible from BO-4100c-1's
  own evidence.
```
