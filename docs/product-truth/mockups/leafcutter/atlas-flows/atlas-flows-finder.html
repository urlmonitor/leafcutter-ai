Flow finder: search and filter every flow

The bare /flows address is a finder overview, not a drawn flow. One search box covers flow names, step labels and text, io_contracts field names, and AC ids, entities and screens. Facets with counts narrow the results; results are grouped by flow, and a matching step opens the flow at /flows/<product>/<flow>?step=<id>. The search and every chosen filter live in the /flows query string, so a search can be shared; flow addresses stay canonical and carry no filters. The result summary is announced through a polite live region. Eleven finder states follow, from FlowFinderQuery.
