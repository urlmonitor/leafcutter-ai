# The workflow test harness raises a contract violation on an instruction-less dispatch

## Actor / Goal

As the leafcutter-ai system, I want to implement AC `BP-1100f-4` — The workflow test harness raises a contract violation on an instruction-less dispatch — so that the acceptance criterion is satisfied.

## Context

This ticket was generated from AC store entry `BP-1100f-4`. Component: `build-pipeline`. Assigned agent: `python-coder`. Estimated complexity: `M`. Complexity: `medium`.

## Acceptance Criteria

```gherkin
Given a workflow test exercises a workflow that dispatches a step whose request's first
  argument is an object or empty value carrying no instruction string,
When the workflow test harness intercepts the dispatch,
Then the harness raises a contract violation that names the instruction-less dispatch and
  fails the test, so such a dispatch cannot pass unseen,
And the harness raises no such violation when the dispatched request's first argument is a
  non-empty instruction string.
```
