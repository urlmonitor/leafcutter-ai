## Implementation Notes

```yaml
- 'No redirect for the bare /flows: neither leafcutter-web/middleware.ts nor leafcutter-web/next.config.mjs
  may redirect or rewrite /flows when the request carries no ''flow'' query parameter;
  the legacy 308 of UXP-591-2-iii keys on that parameter alone.'
- The default entry flow id (leafcutter/deliver-a-feature) is defined in exactly one
  place and shared by the bare-/flows render (leafcutter-web/app/flows/page.tsx) and
  the drawer replace on bare /flows (UXP-591-4, UXP-591-4-ii); no second literal.
- The bare entry goes through the same FlowsView initial-props path as a canonical
  address (flow = default entry, crumbs = [default entry], filters Real/User/All,
  step null), so the two entries cannot drift.
- 'The client must not rewrite /flows on mount: the address only changes on a drawer
  action (UXP-591-4) or a navigation (UXP-591-5).'
```
