## Acceptance Criteria

```gherkin
Given an agent registry entry for "research-agent" with skills_invoked
  containing only an entry for "signoff"
And the agent's template body contains an instruction to invoke the
  knowledge-query skill (e.g. a directive like "load the knowledge-query
  skill" or a Skill tool invocation pattern referencing "knowledge-query")
When the build cross-references each agent's skills_invoked array
  against skill references found in its template body
Then it emits a warning for each skill referenced in the template
  but absent from skills_invoked:
  "research-agent: template references skill 'knowledge-query' but
   skills_invoked does not declare it"
And it emits a warning for each skill declared in skills_invoked
  but not referenced anywhere in the template body:
  "research-agent: skills_invoked declares 'orphan-skill' but
   no reference found in template body"
And both warning directions are checked (template -> registry AND
  registry -> template)
```
