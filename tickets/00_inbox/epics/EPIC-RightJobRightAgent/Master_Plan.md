# EPIC-RightJobRightAgent

## Goal

Build the IT-PO split (L0 ACD-2500, "Every part of a requirement is written by whoever can actually get it right"): a deterministic rule check after each authoring stage (ACD-2500a), the IT PO recording test intent only (ACD-2500b), a code-aware test-designer agent writing test designs and file findings before approval (ACD-2500c/d), and the IT PO's own instructions and profile slimmed to its remaining duties (ACD-2500e). Also builds the ticket generator reading declared_files (TKT-600a-3/-3-i, with the ADR-010 amendment TKT-600a-4), the declared-files reference doc (ACD-1600c-5), and two prerequisites from outside the tree that ACD-2500 depends on: the readiness gate ACD-1600c-1 (+ -1-i) and the surface-to-specialist map ACD-1700b-1 (+ -1-i).

Ship-together pairs (one change each, guaranteed by the single epic PR): ACD-2500b-1 + b-1-i, ACD-2500d-5 + d-5-i, ACD-2500d-3 + d-3-i.
