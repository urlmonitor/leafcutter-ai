## Acceptance Criteria

```gherkin
Given the reusable-criteria goal waiting for its split proposal,
When the host proposes four parts, each naming decision as the capability that will run it:
  p1 "Decide which new file type the reusable categories are put into (needs evaluation)",
    quoting "we can should put them into a new file type (needs evaluation)", waiting for no
    part,
  p2 "Decide how the reusable categories are then also put into Neo4j", quoting "and then also
    into neo4j", waiting for p1,
  p3 "Decide how the reusable categories are clustered", quoting "we must make sure that we are
    able to cluster them somehow", waiting for p1,
  p4 "Decide whether to mine the reusable categories from Langfuse as a start", quoting "As a
    start we can probably mine them from langfuse", waiting for no part,
Then the split gate offers p1 to p4 in that order, each with its quote, the parts it waits for
  and its capability,
And the run waits for a person's answer (run status waiting_human) with every part not run,
And the parts come only from the host's proposal: Jev is not asked to write, merge or reword any
  part.
```
