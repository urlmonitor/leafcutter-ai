# 05: Self-Healing Hook

## Goal
Implement ensure_precommit_config.py, register it as the first (index-0) hook in the commit-guardian manifest, and guarantee that any commit re-materializes a missing .pre-commit-config.yaml via symlink or copy.

## Context
Stub generated by create-epic. This ticket implements the self-healing mechanism:
- ensure_precommit_config.py: re-materializes .leafcutter symlink or copies .pre-commit-config.yaml
- Registered at manifest index 0 (FIRST, before all other hooks)
- Atomic and idempotent (safe to call repeatedly)
- Uses git-common-dir resolver from ticket 02 to locate main tree
- Templates mirror for ADR-001 parity
- This is the SINGLE live config-establishment path (supersedes interim SKILL.md slice)

## Implementation Tasks

### python-coder
- [x] Create ensure_precommit_config.py (scripts/commit_guardian/)
  - On any commit, check if .pre-commit-config.yaml resolves to a readable file
  - If missing/unreadable:
    - Try to create a .leafcutter symlink to the main tree's .leafcutter
      (using git-common-dir resolution from ticket 02)
    - If symlink fails (NTFS/Windows), copy the main tree's .pre-commit-config.yaml instead
  - Exit 0 only if config is resolvable after the hook runs
  - Exit non-zero if re-materialization fails
  - Idempotent: safe to call multiple times (config already exists → no-op, exit 0)
  - Atomic: symlink/copy operation must complete fully or fail completely
- [x] Register in commit_guardian.json at index 0 (FIRST hook)
  - Canonical source is templates/scripts/commit_guardian/commit_guardian.json
  - MUST be listed before all other hooks
  - Assert manifest index 0 in tests
- [x] Create templates/ mirror: templates/scripts/commit_guardian/ensure_precommit_config.py
  - Verify byte-for-byte parity via build.py round-trip per ADR-001
- [x] Integrate with build_precommit.py
  - ensure_precommit_config entry is emitted into generated .pre-commit-config.yaml
