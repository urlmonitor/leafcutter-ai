## Acceptance Criteria

```gherkin
Given a previous authoring run for the same feature crashed and left behind
  an authoring worktree and its branch on disk,
When a new AC-authoring run for that same feature begins,
Then the workflow detects the pre-existing authoring worktree and branch
  before attempting to create a new one,
And it reuses the existing authoring worktree and branch instead of failing
  with a "worktree already exists" error,
And it does not delete or overwrite any AC YAML files already committed on
  that branch,
And if no usable prior worktree exists, it creates a fresh one as in the
  normal path.
```
