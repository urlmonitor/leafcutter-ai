## Acceptance Criteria

```gherkin
Given the location the workspace maker would use for "alpha" is already
  occupied, in turn, by: a copy of the project on a different line of work; a
  copy of a different project; and an ordinary folder of files that is not a
  workspace,
When "alpha" is requested in each case,
Then the answer is a refusal stating that the location is occupied and what
  occupies it,
And the occupant's files and, where it has one, its line of work are identical
  before and after,
And no workspace for "alpha" is made at any other location instead.
```

- [ ] AC-1: the answer is a refusal stating that the location is occupied and what
- [ ] AC-2: the occupant's files and, where it has one, its line of work are identical
- [ ] AC-3: no workspace for "alpha" is made at any other location instead.

  Behaviorally, Not by Grep'); a test never falls back to the templates/ source copy.

  not spawn their own build.py''): the deployed maker comes from the shared deployed
  layout, and fixture projects carry a minimal stub build entry point that installs

  and build its own copy says so and justifies it in its ticket.'

  and run git with an isolated global and system config; afterwards the developer's
