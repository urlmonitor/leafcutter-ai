## Acceptance Criteria

```gherkin
Given five checks that are present in the installed package, described to the reader as
  protecting their work, and named by no entry on the list that causes checks to run,
  so that no commit has ever run any of them,
And a change whose staged content is content the same repository accepted before those
  five were made to run,
When an ordinary commit is performed — no extra command, no extra flag, nothing invoked
  by hand,
Then each of the five is run, at the point in the commit its own subject belongs to,
And the commit completes, so no one of the five refuses work that was acceptable the
  day before they were switched on,

And given the state the repository already stands in at the moment they first run —
  including the directories that already hold more files than the density limit permits,
When an ordinary commit is performed that does not make that state worse,
Then the state that already existed is reported as it stands and does not by itself
  refuse the commit, and only what this change makes worse is objected to,

And given a check among the five whose subject this repository holds no instance of, so
  that it has nothing to examine here,
When it runs,
Then it says that it had nothing to examine, rather than reporting that it examined
  something and found it clean,

And given, for each of the five, an input that check exists to refuse, under the
  settings that arm it,
When that input is put through the commit path the check is now registered on,
Then the check refuses it and names what it objected to — so what has been switched on
  is a check that can still say no, and not five entries that are certain never to
  object,

And after this change the record of advertised checks that nothing runs is smaller by
  exactly these five, and names none of them.

Coverage note: the first two arms are covered by attempting real commits and asserting
the outcome; the fourth is covered by putting the refusable input through the registered
commit path rather than by invoking the check by hand, because a check that refuses when
called directly and is never called is the defect this whole record exists to end.
```
