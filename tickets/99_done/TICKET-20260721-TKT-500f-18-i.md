## Acceptance Criteria

```gherkin
This edge case bounds TKT-500f-18 so a broken mapping source degrades safely
rather than breaking every caller that imports the generator.

Given the kebab-to-graph-id mapping source is malformed or unavailable — for
  example docs/components.json is missing or contains invalid JSON, or a sibling
  data module raises a SyntaxError or other error when loaded,
When scripts/ac_store/generate_ticket_from_ac.py is imported,
Then the import succeeds and does not raise: the malformed/unavailable source is
  caught and the generator degrades to a logged fallback mapping (an empty or
  minimal mapping) with a WARNING that names the failed source,
And ticket generation still proceeds using the fallback mapping (component values
  that cannot be resolved follow the TKT-500f-17 warn-and-surface path rather than
  crashing the generator),
And the fallback is reached only on a genuine load failure — a well-formed
  components.json is still loaded and used normally (no regression of
  TKT-500f-18).
```
