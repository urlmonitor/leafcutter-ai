# A proof that reached the code by direct import does not make a criterion done when the code has a real way in

## Actor / Goal

As the leafcutter-ai system, I want to implement AC `BO-2900a-1` — A proof that reached the code by direct import does not make a criterion done when the code has a real way in — so that the acceptance criterion is satisfied.

## Context

This ticket was generated from AC store entry `BO-2900a-1`. Component: `build-orchestration`. Assigned agent: `python-coder`. Estimated complexity: `M`. Complexity: `medium`.

## Acceptance Criteria

```gherkin
Given an acceptance criterion whose implementing code lives in a unit that exposes
  a runtime way in — an operator-invocable command surface that accepts a named
  action and its arguments,
  And the criterion's proof-of-done test is present, executes real code, and passes,
  And that test reaches the implementing function by importing it directly and
    calling it, so the unit's way in is never entered while the test runs,
When the criterion is evaluated for eligibility to be marked done,
Then the criterion is rejected as not eligible,
  And the rejection names the unit, the way in that was never entered, and the test
    that reached the code by import instead,
  And with no other change to the code and no additional assertion, the same
    criterion becomes eligible once a proof test drives the same behaviour by
    invoking the way in with the action and arguments an operator would use,
  And a criterion whose implementing unit exposes no runtime way in at all is not
    judged by this rule — that case is decided separately.
```

- [ ] AC-1: the criterion's proof-of-done test is present, executes real code, and passes
- [ ] AC-2: that test reaches the implementing function by importing it directly and
- [ ] AC-3: the criterion is rejected as not eligible
- [ ] AC-4: the rejection names the unit, the way in that was never entered, and the test
- [ ] AC-5: with no other change to the code and no additional assertion, the same
- [ ] AC-6: a criterion whose implementing unit exposes no runtime way in at all is not
