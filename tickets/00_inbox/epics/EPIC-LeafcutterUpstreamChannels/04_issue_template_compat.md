# 04: Create .github/ISSUE_TEMPLATE/compat.yml on leafcutter-ai

## Goal

In order to collect structured compatibility and consumer integration reports from downstream projects using `leafcutter-ai` as a submodule, we need a GitHub Issue form that captures the consumer project type, leafcutter version, and description of the incompatibility.

## Context

Stub generated by create-epic. Harden with create-ticket (depth 3).

All changes are on the `urlmonitor/leafcutter-ai` upstream repo. This ticket can run in parallel with 01, 02, 03, 05, 06, 07, 08.

This template is distinct from the bug template — it's for integration-level issues (e.g. "your build script breaks when used with Poetry 2.x") rather than bugs in leafcutter's own logic.

## Acceptance Criteria

```gherkin
Given leafcutter-ai is published on GitHub and config.yml disables blank issues
When a user selects "Compatibility Issue" from the issue template picker
Then they see a structured form with fields: consumer project type, leafcutter version, description of incompatibility
And the issue title is prefixed with "[Compat] "
And required fields are marked required
```
