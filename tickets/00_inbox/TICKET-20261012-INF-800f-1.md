## Acceptance Criteria

```gherkin
Given a ticket is being driven whose change was written by python-coder,
And the drive brings in the restructuring specialist after a refusal,
When the run's ordered record of parties engaged is read,
Then it holds an entry for the restructuring specialist under its own agent id, found
  in the agent registry,
And that id is not python-coder nor the id of any other coder, so the specialist is a
  different party from the coder that wrote the change.

Given the restructuring specialist is engaged with a complexity demand naming
  scripts/planner.py, the function plan_batches, complexity 31 and 30 allowed,
When the specialist finishes,
Then the report it returns names complexity-reduction as the skill it applied to
  plan_batches.

Given the restructuring specialist is engaged instead with a file-size demand of 120
  measured lines to leave scripts/planner.py,
When the specialist finishes,
Then the report it returns does not name complexity-reduction, so the skill is chosen
  by the demand and is not applied on every engagement.
```
