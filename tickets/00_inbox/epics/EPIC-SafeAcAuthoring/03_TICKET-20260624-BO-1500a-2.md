## Acceptance Criteria

```gherkin
Given the user's original checkout has uncommitted changes
  and a second, concurrent worktree exists for an unrelated session,
When the AC-authoring workflow runs from start to finish in its dedicated
  authoring worktree,

  unchanged when the workflow ends (no files added, modified, deleted,
  staged, committed, or branch-switched there),
And the concurrent worktree's working tree, index, and branch are likewise
  unchanged,
And the only filesystem and git changes made by the workflow occur inside
  the authoring worktree.
```
