## Entry

Four problems seen while building the eval that scores the tests test-writer produces are now
recorded as known issues.

The list of existing tests a test writer changed is saved against the commit checked out at the
time. Once the branch takes in the latest main and the work is checked against the shared base,
that list no longer counts, and the work stops with "sweep list missing" although the list was
saved. A timing test for the step that lists what the wrong-version runs owe compares one short
run with one long run; both are mostly start-up cost, so it fails at random and passes on rerun.
On Windows the eval harness cannot start the `claude` command the standard install provides, so
every live eval scores zero until the path is changed by hand. And the eval for the restructuring
agent scores zero because the agent's replies did not carry the labels the eval reads. Each entry
names the affected lines and the suggested fix; none of the fixes is applied yet.
