## Implementation Notes

```yaml
- A session-level guard snapshots the developer repository (`git worktree list --porcelain`,
  `git for-each-ref`, `git config --local --list`) before the workspace proof suite
  and compares after; any difference fails the session. Fixture git runs with isolated
  HOME / GIT_CONFIG_GLOBAL / GIT_CONFIG_NOSYSTEM so no fixture identity reaches the
  real config.
- All temporary projects, hubs and workspaces live under the test's temp directory
  and run git with an isolated global and system config; afterwards the developer's
  own repository's branches, registered worktrees and local git config are unchanged
  (BO-4300f-4-i, F14, KI-TQ-012).
```
