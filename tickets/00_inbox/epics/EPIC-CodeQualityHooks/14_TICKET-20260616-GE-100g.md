## Acceptance Criteria

```gherkin
Given the onboarding wizard is running its hook configuration step
And the jscpd binary IS detected on the system PATH
When the wizard reaches the duplicate-code hook configuration prompt
Then it asks the user whether to enable the duplicate code check

And it adds "jscpd (duplicate code detection)" to the post-onboard
  checklist of optional tools the user can install later
```

module that detects `jscpd` and `diff-cover` binaries on PATH via `shutil.which()`. When
a binary is found and stdin is a TTY, the user is prompted yes/no; on acceptance the
corresponding `<section>.enabled` flag is set to `true` in `commit_guardian.json` via an
atomic temp-file-then-rename write. When a binary is absent the tool label is silently
added to a returned `optional_tools_checklist` for the post-onboard checklist. Non-TTY
environments (CI) skip all prompts and make no changes.
