# A reference lists every /flows finder address parameter with its stored values and labels

## Actor / Goal

As the leafcutter-ai system, I want to implement AC `UXP-617-5` — A reference lists every /flows finder address parameter with its stored values and labels — so that the acceptance criterion is satisfied.

## Context

This ticket was generated from AC store entry `UXP-617-5`. Component: `ux-prototyping`. Assigned agent: `documentation-expert`. Estimated complexity: `S`. Complexity: `low`.

## Acceptance Criteria

```gherkin
Given a shared finder link such as /flows?q=selected+option&actor=human depends on its
  parameter names and values staying stable,
When a person looks up what a finder address means in the reference documentation,
Then the reference lists the eleven parameters q, product, actor, kind, realization, level,
  uses, produces, io, entity and screen, each with the filter label it belongs to,
And for each parameter with a fixed vocabulary it lists every stored value next to the label
  the finder shows: actor deterministic = Code, llm = AI agent, human = Person and jev = Jev;
  kind user = User, data = Data and architecture = Architecture; realization built = Built,
  spec = Spec and mock = Sample; level journey = Journey, pipeline = Pipeline and
  agent = Agent; io gap = 'I/O not yet defined',
And it states that product, uses, produces, entity and screen take a product slug, a field
  key, an entity name and a screen id respectively, never a display label,
And it states that repeating a parameter combines its values with OR and that different
  parameters combine with AND,
And it states that a finder address never carries a flow or a step parameter, and that a flow
  has its own address /flows/<product>/<flow>, optionally with ?step=<id>,
And the Atlas routes table lists the bare /flows as the finder rather than a default flow.
```

- [ ] AC-3: it states that product, uses, produces, entity and screen take a product slug, a field

- [ ] AC-5: it states that a finder address never carries a flow or a step parameter, and that a flow
- [ ] AC-6: the Atlas routes table lists the bare /flows as the finder rather than a default flow.
