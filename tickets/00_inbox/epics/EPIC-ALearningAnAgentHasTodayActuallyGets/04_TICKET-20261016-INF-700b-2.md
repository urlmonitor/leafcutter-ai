## Actor / Goal

As the leafcutter-ai system, I want to implement AC `INF-700b-2` — A template that names a step which does not exist is refused by the repository's own gating — so that the acceptance criterion is satisfied.

## Context

This ticket was generated from AC store entry `INF-700b-2`. Component: `infrastructure`. Assigned agent: `python-coder`. Estimated complexity: `M`. Complexity: `medium`.

**Repo-admin step, not code.** Making the new CI job a *required* status check on `main` (enforcement point 3 below, the only point that satisfies "refused rather than merely reported") is a change to the main-branch ruleset (Ruleset `require-ci-lint`), which needs repository-admin rights. No agent on this ticket can perform it. python-coder delivers points 1 (hook manifest entry) and 2 (CI job); at sign-off, state explicitly that point 3 is pending a repo-admin action rather than declaring AC-3 met.

**Deploy manifest.** `build_commit_guardian` in `scripts/build_phases_lifecycle.py` copies the whole `templates/scripts/commit_guardian/` directory, so a new `templates/scripts/commit_guardian/check_skill_refs.py` deploys without an allowlist edit. That file is listed in files_touched so the coder verifies the deploy (build, then run the deployed hook) and edits it only if the directory copy does not reach the new module.

## Acceptance Criteria

```gherkin
Given a shipped agent or skill template is changed so that it instructs an
  agent to load a skill directory that is not present in the package,
When the change is put through the repository's own gating path — the
  commit-time hook run and the continuous-integration run, each invoked the
  way the repository itself invokes it rather than by calling the checking
  script directly,
Then both runs fail,
And each failure names the offending template file and the skill name that
  does not resolve,
And the change is refused rather than merely reported, so it cannot reach the
  default branch while the reference is unresolved,
And when the same two runs are made over a tree in which every skill named by
  a template resolves to a real directory, both pass and report no violation,
And a tree in which the checking script is present but is not reached by
  either run is treated as a failure of this criterion, not a pass.
```
