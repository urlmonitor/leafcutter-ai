## Acceptance Criteria

```gherkin
Given finalize halts partway through the sequence (for example a test
  regression is detected before the pull request is merged),
When the halt summary is produced,
Then the summary reports which steps completed with their recorded outcomes,
  names the step at which the run halted, and states the reason for the halt
  together with the remediation the user must take,
And the mainline-affecting steps that were never reached are not reported as
  completed.
```
