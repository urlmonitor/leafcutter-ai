## Context

## Acceptance Criteria

```gherkin
Given the check-exception-handling pre-commit hook receives a staged Python file,
And the file is a test file — its path contains a `tests` or `unit_tests`
  component, OR its basename matches `test_*.py`, `*_test.py`, or `conftest.py`,
When the hook runs,
Then the file is skipped without AST analysis,
And no E722, BLE001, or IO-001 violation is emitted for that file,
And the hook exit code is not raised to 1 on account of that file's contents,
And a non-test production `.py` file with the same violations is still
  blocked (exit 1), so the exemption never widens to production code.
```
