## Acceptance Criteria

```gherkin
Given an agent author needs to know what the knowledge-capture step requires
  of an agent before writing a new agent template,
When they open the reference documentation for the agent knowledge system,
Then it states each field a knowledge record carries, including the learning
  text itself, and what each field is for,
And it states what an agent does when it has no learning to record,
And it states what an agent does when capture cannot complete, and where that
  failure is recorded so it can later be counted,
And every directory, file and step the reference names exists in the package
  at the location given,
And it describes no step that ADR-034 retired as something an agent takes,
And it does not state or imply that a captured learning reaches its surface
  automatically while no trigger for the routing step exists.
```
