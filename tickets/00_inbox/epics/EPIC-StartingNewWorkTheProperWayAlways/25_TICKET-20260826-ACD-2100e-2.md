# A how-to guide takes an operator from a waiting run back to a running one

## Actor / Goal

As the leafcutter-ai system, I want to implement AC `ACD-2100e-2` — A how-to guide takes an operator from a waiting run back to a running one — so that the acceptance criterion is satisfied.

## Context

This ticket was generated from AC store entry `ACD-2100e-2`. Component: `ac-driven-dev`. Assigned agent: `documentation-expert`. Estimated complexity: `M`. Complexity: `medium`.

## Acceptance Criteria

```gherkin
Given an operator who has found a run that stopped and reported that it is
  waiting for an answer,
When they open the project's how-to guides,
Then a page tells them how to list the runs that are waiting and how to see
  which decision each one is waiting on,
And it gives the invocation that starts the route again supplying the person's
  answer for that decision -- the invocation the route itself accepts rather
  than an edit of the stored record by hand,
And it states what the operator observes in each of the three ways that
  invocation ends: the run continuing from the decision it was waiting on
  without repeating the steps before it and no longer listed as waiting; the
  run reporting there is nothing to resume when no waiting record exists; and
  the run staying waiting and naming the decision that is outstanding when the
  answer supplied names a different decision,
And for each of the two endings that do not resume it states that the drafted
  work is unchanged and the waiting record is still there to be answered,
And each step and each outcome it gives names the criterion whose delivered
  behaviour it describes,
And the page is reachable from the documentation index and declares the same
  component as this criterion.
```
