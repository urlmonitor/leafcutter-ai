## Acceptance Criteria

```gherkin

  (the list form used on BO-1000c-1b and BO-1000c-2), not the structured
  reference_file_path form,

  (for example a bullet reading "Modify scripts/goal_to_epic.py to ..."
  naming "scripts/goal_to_epic.py"),
When a ticket is generated from that AC by generate_ticket_from_ac.py,

  "scripts/goal_to_epic.py" (the source path extracted from the prose bullet),

  it_requirements, not only for the structured reference_file_path form.

Given a leaf AC whose list-form it_requirements bullets name no source file
  path (prose with no file reference),
When a ticket is generated from that AC,
Then no phantom source path is invented in files_touched, and files_touched
  still contains the AC's doc_links paths.
```
