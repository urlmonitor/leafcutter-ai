# Background finalize appends each progress line to a durable, pollable run-progress journal as it happens

## Actor / Goal

As the leafcutter-ai system, I want to implement AC `BO-1000c-1a` — Background finalize appends each progress line to a durable, pollable run-progress journal as it happens — so that the acceptance criterion is satisfied.

## Context

This ticket was generated from AC store entry `BO-1000c-1a`. Component: `build-orchestration`. Assigned agent: `python-coder`. Estimated complexity: `M`. Complexity: `medium`.

## Acceptance Criteria

```gherkin
Given the finalize-feature workflow is running in the background while the
  user remains in the main conversation,
When the workflow emits a start-of-step or per-step-outcome progress line,
Then that same line is appended, at the moment it is emitted, to a durable
  run-progress record for the run that a caller outside the background run can
  read while the run is still in flight,
And the record preserves the emission order of the lines and is written
  incrementally over the run rather than only flushed once at the end.
```

- [ ] AC-1: that same line is appended, at the moment it is emitted, to a durable
- [ ] AC-2: the record preserves the emission order of the lines and is written
