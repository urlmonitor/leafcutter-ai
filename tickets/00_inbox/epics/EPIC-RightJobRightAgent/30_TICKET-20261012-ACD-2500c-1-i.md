## Implementation Notes

```yaml

- Path existence is judged against the authoring worktree's tree at check time.
- '''To-be-created'' is accepted only when the path is among the record''s declared
  files with state ''to_be_created'', read through the declared-files seam of ACD-1600c-4
  (field declared_files) -- the store''s single answer, the same one ACD-2500a-3 reads;
  no doc_links derivation. For a record in the ''no declared files'' state a to-be-created
  entry cannot be confirmed, so it is reported ''not evaluated: no declared files''
  -- never passed and never rejected; entries naming existing files are still judged
  on existence.'
- Applies only to designs carrying the code-aware authorship mark; legacy designs
  are exempt (ACD-2500b-3).
```
