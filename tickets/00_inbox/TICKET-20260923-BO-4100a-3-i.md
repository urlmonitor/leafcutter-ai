## Implementation Notes

```yaml
- The refusal must decide before it writes. ADR-039's occupied-workspace refusal already
  establishes a 'no fetch, no branch, no directory' posture for a refusal path in
  this same script; that ordering is the model. Where a write genuinely must precede
  the decision, the undo must be performed AND verified, never assumed.
- Cleanup must be scoped to what THIS request created. It must never remove a directory,
  branch or registration entry that existed before the request -- a refusal that tidies
  up a pre-existing neighbour is a worse failure than the debris it was avoiding.
- 'Applies to every refusal path in creation, not just the unreadable-shared-line
  one: BO-4100d-2''s unsupported-kind refusal and BO-4100a-2''s post-condition failure
  reach the same guarantee, so the no-debris behaviour belongs at the refusal boundary
  rather than in one branch.'
- Both the canonical template and its scripts/ build output must carry the change
  (ADR-001).
```
