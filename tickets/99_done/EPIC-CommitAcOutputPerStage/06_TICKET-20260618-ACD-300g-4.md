## Acceptance Criteria

```gherkin
Given the /create-ac workflow has completed a stage and the authoring agent
  has written AC YAML files to the AC store with readiness: draft,
When the user chooses "cancel" at the confirmation gate,
Then the workflow does NOT create a git commit for that stage's output,
And the draft AC YAML files remain on disk as uncommitted working-tree changes,

And the user can inspect the files, manually commit them, or discard them
  with a standard git checkout.

Given the /create-ac workflow has completed stage 1 (PO v3, committed)
  and stage 2 (BA v3, not yet approved),
When the user chooses "cancel" at gate 2,
Then the stage 1 commit remains in git history (it was already committed),
And only the stage 2 draft files remain uncommitted on disk,
And the workflow exit message distinguishes between "committed ACs from
  prior stages" and "uncommitted draft ACs from the canceled stage".
```
