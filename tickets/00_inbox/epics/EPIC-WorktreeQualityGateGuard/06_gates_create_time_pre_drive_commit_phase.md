# 06: Gates: Create-Time + Pre-Drive + Commit-Phase

## Goal
Implement three quality-gate checkpoints: (1) create-time gate in setup_ticket_worktree.py _bootstrap verifying config is resolvable, (2) pre-drive gate in building-epics SKILL §1.0.1, and (3) commit-phase gate in commit.md refusing to commit without a passing probe.

## Context
Stub generated by create-epic. This ticket wires the three gates that consume the probe (all from ticket 02):
- BO-1700d-1 / d-1-i: Create-time gate in setup_ticket_worktree.py _bootstrap (python-coder)
  - Run after ensure_precommit_config hook (ticket 05) has guaranteed config exists
  - Invoke verify_precommit_active.py and check exit code + failing_checks
  - Halt worktree creation if probe fails
  - Document the gate invocation point
- BO-1700d-2: Pre-drive gate in templates/skills/building-epics/SKILL.md §1.0.1 (llm-expert)
  - At start of epic drive, invoke probe on the epic worktree root
  - Halt if probe fails, surface results to user
  - Document why this gate is needed (protection against mid-drive config loss)
- BO-1700d-3 / d-3-i: Commit-phase gate in templates/agents/commit.md (llm-expert)
  - Before any git commit, invoke probe on worktree root
  - Refuse to commit if probe fails
  - Offer user choice: resolve config issues OR override (explicit auth only)

All three gates consume ONLY the probe result from ticket 02; they do not reimplement the checks.
