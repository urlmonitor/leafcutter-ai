# Verification-required agent with no edit ability is blocked at commit

## Actor / Goal

## Acceptance Criteria

```gherkin
Given a staged agent definition whose settings declare that it must verify
  the changes it makes (requires_verification is true),
And that agent's declared abilities include neither the ability to edit files
  nor the ability to create files (tools lists only read-and-inspect abilities
  such as Read and Bash),
When the commit is attempted,
Then the commit is blocked fail-closed,
And the block is reported as a failure of the consistency guard,
And the offending agent definition is not committed.
```
