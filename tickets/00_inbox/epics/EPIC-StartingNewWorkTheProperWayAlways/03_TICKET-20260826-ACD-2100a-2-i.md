## Implementation Notes

```yaml
- The change must land under templates/scripts/ alongside ACD-2100a-2's resolver;
  the deployed copy is build output.
- 'Fail closed: an ambiguous resolution is a non-zero exit, never a warning that proceeds.
  A worktree created in the wrong project is silent and expensive to unpick.'
- 'The refusal must be atomic with respect to the filesystem: the resolution must
  complete before any branch is created or any directory is written, so a partial
  attempt cannot leave residue in a candidate repository.'
- The refusal message must enumerate every candidate found. A bare 'could not determine
  the repository' sends the operator back to the same search by hand and is not distinguishable
  by a test from a resolver that simply failed.
- 'Must satisfy the repository error-handling policy: raise a typed error rather than
  returning a sentinel that a caller can ignore.'
- 'Must be idempotent: rerunning after the refusal must produce the same refusal,
  not a different outcome caused by residue from the first attempt.'
```
