# The number of agents collaborating on a single feature is capped

## Actor / Goal

As the leafcutter-ai system, I want to implement AC `BO-1800c-1` — The number of agents collaborating on a single feature is capped — so that the acceptance criterion is satisfied.

## Context

This ticket was generated from AC store entry `BO-1800c-1`. Component: `build-orchestration`. Assigned agent: `llm-expert`. Estimated complexity: `M`.

## Acceptance Criteria

```gherkin
Given a single feature/drive is being built,
When agents are assigned to collaborate on that one feature,
Then the count of agents working concurrently on that single feature is capped at
  a small number (the drive runbook cap, on the order of 3-4),
And an attempt to add agents beyond the cap onto one feature is prevented or held,
  rather than piling on more concurrent collaborators.
```
