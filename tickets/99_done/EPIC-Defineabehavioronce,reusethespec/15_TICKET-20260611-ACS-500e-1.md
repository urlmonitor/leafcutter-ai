## Acceptance Criteria

```gherkin
Given the store contains atomic pattern ACs:
  - "sortable-table" (PTN-010) defining column sorting behavior,
  - "filter-bar" (PTN-011) defining text/dropdown filter behavior,
  - "paginated-collection" (PTN-012) defining page-size and navigation,
When a composite pattern "crud-list-page" (PTN-020) is defined,
Then PTN-020's depends_on includes [PTN-010, PTN-011, PTN-012],
And PTN-020's criteria describes ONLY the wiring behavior between them
  (e.g. "filter changes reset pagination to page 1",
  "sort changes preserve current filter state"),
And PTN-020 is itself available as a reusable pattern that consuming
  page ACs can reference via implements_pattern: "PTN-020".
```
