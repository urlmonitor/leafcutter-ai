## Context

## Acceptance Criteria

```gherkin
Given a test function tagged "# covers: <AC-ID>" where <AC-ID> does not match
  any acceptance-criterion present in the AC store,
When the suite is run and that test fails,
Then the test is treated as unlinked and is enforced (its failure counts as a
  real failure and drives the run outcome non-passing)
And the test is never treated as informational on the basis of an
  unresolvable tag
And the unresolved tag is surfaced to the linkage-integrity check (TQ-100c) so
  the dangling reference is flagged.
```
