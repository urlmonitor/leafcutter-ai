## Acceptance Criteria

```gherkin
Given a ticket that requires documentation and the documentation-verifier phase runs,
When a required documentation file was changed in the diff but its content matches a
  placeholder signature -- for example it contains only `TODO` or `TBD` markers, is an
  empty stub, or is an unfilled copy of a template --
Then the verifier reports a failure with `status: blocker` identifying the placeholder file.
And when every required documentation file was changed AND its content does not match a
  placeholder signature, the verifier returns `status: ok`.
```
