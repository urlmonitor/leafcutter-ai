## Context

## Acceptance Criteria

```gherkin
Given a fresh consumer project has run build.py with the default
  commit_guardian.json (both hooks have enabled: false)
When the generated .pre-commit-config.yaml is inspected
Then it does NOT contain an entry for "check-duplicate-code"
And it does NOT contain an entry for "check-diff-coverage"
And no pre-commit hook fires for duplicate detection or coverage gating

---

Given a consumer project has modified commit_guardian.json to set:
  duplicate_code.enabled: true
And diff_coverage.enabled remains false
When build.py regenerates .pre-commit-config.yaml
Then it contains an entry for "check-duplicate-code" in the hooks section
And it does NOT contain an entry for "check-diff-coverage"
And the duplicate code hook fires on the next commit that stages
  a file matching the configured extensions pattern
```
