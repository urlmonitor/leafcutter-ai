## Acceptance Criteria

```gherkin
Given a surfaces configuration that declares some set of surface entries, each
  with a path and edge_fields
When the knowledge map is built
Then every declared surface whose path exists contributes its nodes to the map
And the set of surfaces that contributed is exactly the set declared in the
  configuration (minus any declared surface marked optional whose path is absent)
And no surface is read that was not declared in the configuration
And the build asserts this against the declared set itself, not against any
  fixed expected number of surfaces
```
