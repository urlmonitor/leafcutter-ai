## Implementation Notes

```yaml
- THE OPT-OUT MARKER LIVES IN THE SAME LEADING COMMENT REGION AS THE @ac DECLARATION
  and is read by the same shared reader in the same pass, in both comment dialects
  (GE-124a-2). A separate scan, or a separate marker location, gives the two surfaces
  different placement rules for no reason and doubles the parse cost.
- THE REASON IS IN THE FILE, NEVER IN A CENTRAL LIST. Do NOT add an ignore-list key
  to commit_guardian.json for per-item opt-outs — that is the mechanism the PO explicitly
  rejected, because a reason parked centrally is invisible at review time and rots.
  It being in the file is what makes it appear in the diff, and appearing in the diff
  is the entire accountability mechanism. (The warn list in GE-124d-1 IS central,
  deliberately, because it excuses an AREA and not an item.)
- THE FILE IS LISTED, NOT DISAPPEARED. The report must carry the path AND the verbatim
  reason text. An opted-out file that vanishes from the report is indistinguishable
  from a file the check never saw, and the whole point is that a reviewer can challenge
  the reason.
- THE REASON TEXT IS REPRODUCED VERBATIM, NOT SUMMARISED OR TRUNCATED to a fixed width.
  A truncated reason in the report is a reason nobody can evaluate; if length is a
  concern, wrap rather than cut.
- PASS-WITH-REASON IS A DISTINCT VERDICT VALUE, not a pass with a comment attached
  — GE-124d-3 fixes it as the single recorded verdict for the file, replacing block.
  The mock record gf-commit-ui-kit-optout is the worked shape, including suppression_reason
  being populated exactly when the verdict is pass-with-reason.
- THE DIFF-VISIBILITY CLAUSE IS A PROPERTY OF THE DESIGN, NOT A RUNTIME CHECK. The
  check must not attempt to inspect the diff to verify the reason is visible; storing
  the reason in the file makes it visible by construction. Do not implement scenario
  2 as a git operation — implement it by not having a central list.
- Must handle errors gracefully per the project error handling policy; a malformed
  or empty reason is GE-124d-2-i's contract and leaves the file blocked.
```
