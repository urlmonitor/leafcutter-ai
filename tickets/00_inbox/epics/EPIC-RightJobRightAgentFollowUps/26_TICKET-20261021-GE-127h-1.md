## Acceptance Criteria

```gherkin

  change, made of code, ordinary "#" comments and blank lines,
  followed by a decision-history block of 25 comment lines: a rule line of "=" characters,
  the heading "# DECISION HISTORY", a second rule line, and 22 entry lines each starting
  "# - " or "#   ",
  and a JavaScript file that measures 120 lines before this change, whose header carries a
  decision-history block of 15 "//" comment lines (the heading "// DECISION HISTORY" with
  no rule lines, then 14 entry lines),
When the length of each file is measured,
Then the Python file measures 80 and the JavaScript file measures 120,
And the same holds for the line-comment form of every other language the standard covers
  (for example "-- DECISION HISTORY" in SQL and "# DECISION HISTORY" in shell),
And every line outside the block is measured exactly as it was before this change,
  including ordinary comments, docstrings, JSDoc and blank lines,
And a file with no decision-history block measures the same length as before this change,
And a decision-history block that sits inside text the rule in force already leaves out (a
  module docstring or a block comment) is not subtracted a second time, so that file
  measures what it measured before this change.
```

## Implementation Notes

```yaml
- Changed in the one measurement function of the size standard (templates/scripts/commit_guardian/_file_size_ratchet.py).
  Every gate that measures length (crossing, growth ratchet, published-rule agreement)
  picks the change up; there is no second implementation.
- Lands in the same change as GE-127h-3, so the published rule and the measurement
  change together; otherwise the rule-agreement check of GE-127d-1 fails.
- A file whose measured length drops because of this change is not reported as a violation,
  and no stored baseline needs a hand edit.
- 'IT PO decision on the comment-prefix source: the measurement takes no language,
  and the config holds only checked_extensions and limits, so the line-comment prefixes
  (#, //, --) are held once as a constant in templates/scripts/commit_guardian/_file_size_ratchet.py.
  A block starts at a line whose text after one of those prefixes is exactly DECISION
  HISTORY and continues over lines that start with the same prefix as its heading,
  so no per-extension mapping is needed and every checked extension is covered. The
  published rule names the three prefixes.'
- 'A block does not need ''='' rule lines: about 50 of the headings in the repository
  have none.'
- Measuring stays linear in file length.
```
