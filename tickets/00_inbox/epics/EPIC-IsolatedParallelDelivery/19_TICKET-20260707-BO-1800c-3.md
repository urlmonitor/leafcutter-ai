## Acceptance Criteria

```gherkin
Given many independent drives are running and the host approaches a resource
  ceiling (for example memory pressure),
When the scheduler decides whether to keep, pause, or start drives,
Then it makes the decision from live host-resource signals rather than a fixed
  feature-count cap,
And under memory pressure it sheds idle drives (pauses or stops drives doing no
  active work) to relieve the host,
And active, progressing drives are preferred over idle ones when resources are
  constrained.
```
