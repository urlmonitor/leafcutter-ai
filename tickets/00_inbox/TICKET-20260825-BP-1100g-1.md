## Implementation Notes

```yaml
- THE TAUGHT SET MUST BE MACHINE-EXTRACTABLE. Write it into templates/agents/test-writer.md
  behind one stable anchor (a single fenced block or a table under a fixed heading)
  so the comparison can read the real source. Prose that merely mentions the names
  is not a set and cannot be compared; a taught set the checker cannot find is the
  same as no taught set.
- The comparison must read BOTH sides from where they really live — the single definition
  established by BO-2900g-3, and templates/agents/test-writer.md — never a fixture
  copy of either. A comparison against a convenience copy reproduces exactly the EPIC-ComputedQualityGates

  it. 'The sets differ' is unactionable.
```

### Scope correction — READ BEFORE EDITING ANY TEMPLATE

The generated `files_touched` named `.claude/agents/test-writer.md` as an edit
surface. It was wrong, and it has been removed. `.claude/agents` is a **symlink to
`.leafcutter/agents`** — a build output that `build.py` regenerates from
`templates/`. The path is not one of the AC's five `doc_links`; the generator's prose
fallback scraped it out of the it_requirement above that *warns* the deployed copy
must also carry the taught set (KI-ACS-002).

**Edit `templates/agents/test-writer.md`. Never the deployed copy.**

Getting this backwards produces a green ticket that ships nothing, and it is worth
understanding exactly how, because this AC exists to prevent that failure:

1. `test_spec` entry 4 is the **reachability** test. It runs `build.py` and then reads
   the DEPLOYED `.claude/agents/test-writer.md` — deliberately, because the agent
   runtime loads the built copy, and a source-tree read is structurally blind to a
   deploy-manifest gap.
2. Edit the deployed copy directly and that test passes **immediately**.
3. `templates/` is untouched, so the next `build.py` run overwrites the deployed copy
   and the taught set disappears.
4. The ticket has closed green. Nothing shipped.

The deployed copy is the **assertion target**, not the edit target. It earns the
taught set by being rebuilt from `templates/`, which is precisely what entry 4 is
checking.

`out_of_scope` now lists `.claude/agents/` and `.leafcutter/`, so `change-scope-reviewer`
treats a diff there as a hard violation rather than a judgement call.

Also added to `files_touched`: `unit_tests/prompt_assembly/test_bp_1100g_1.py`. All four
`test_spec` entries target that directory and it was absent from the declared surface,
which would have made the actual deliverable read as unexpected scope.
