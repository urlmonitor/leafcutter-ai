## Implementation Notes

```yaml
- PRODUCTION MUST BE DEFERRED TO FIRST DEMAND, NOT TO SESSION START AND NOT TO COLLECTION.
  Collection is measured at 5.33s and touches every test module, so a layout produced
  during collection, at plugin import, or by an autouse fixture is created for every
  run including a single-test one. The trigger must be the first actual request for
  the layout root.
- LAZINESS IS PER WORKER AS WELL AS PER RUN. Under pytest-xdist a worker to which
  no consumer is scheduled must produce nothing. Assert both scopes; a run-level "at
  least one consumer existed somewhere" test passes while every idle worker still
  pays 59.8s.
- 'The zero case must be observable two ways that can disagree: the reported count
  is 0 AND no deploy subprocess was executed. A fixture that deploys and reports 0
  satisfies only one of them.'
```
