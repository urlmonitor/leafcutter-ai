## Acceptance Criteria

```gherkin
Given a developer adds a new agent template file at templates/agents/new-agent.md

  but WITHOUT a "produces" field,

When the validation test (BO-510-3) runs as part of the pre-commit hook
  or CI pipeline,

  "Template 'templates/agents/new-agent.md' is missing the 'produces' frontmatter field"
And the commit is blocked until the produces field is added to both locations

Given the developer then adds produces: production_code to both the registry
  entry and the template frontmatter,
When the validation test runs again,
Then it PASSES and the commit proceeds
```
