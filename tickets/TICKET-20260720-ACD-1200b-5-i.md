## Acceptance Criteria

```gherkin
Given a goal AC whose leaf children span mixed readiness states:
  - ACD-050a-1 (readiness: approved)
  - ACD-050a-2-i (readiness: reviewed)
  - ACD-050b-2 (readiness: draft)
When the approval mechanism is invoked against that goal,
Then only ACD-050a-2-i is promoted (reviewed -> approved),
And ACD-050a-1 is left unchanged (already approved: no re-stamp, no duplicate
  amended_by entry, no field mutated),
And ACD-050b-2 is left unchanged (readiness: draft is below reviewed and is not
  promoted; a draft leaf is never jumped straight to approved by this
  mechanism),
And the run reports which leaves were promoted and which were left unchanged.

Given a goal AC all of whose leaf children are already approved,
When the approval mechanism is invoked against that goal,
Then no AC file is modified and the run completes successfully reporting zero
  promotions.
```
