# Nested and dynamic route segments derive a single deterministic doc path

## Actor / Goal

As the leafcutter-ai system, I want to implement AC `GE-104a-1-ii` — Nested and dynamic route segments derive a single deterministic doc path — so that the acceptance criterion is satisfied.

## Context

This ticket was generated from AC store entry `GE-104a-1-ii`. Component: `guardrail-engine`. Assigned agent: `python-coder`. Estimated complexity: `S`.

## Acceptance Criteria

```gherkin
Given a newly added frontend page at a nested route site/app/parts/list/page.tsx
When the guardrail derives the expected reference doc path for that page
Then it produces exactly one deterministic reference doc path under
  docs/reference/frontend/ that uniquely identifies the nested route
And two different nested routes never collapse to the same doc path

---

Given a newly added frontend page at a dynamic route segment
  site/app/parts/[id]/page.tsx
When the guardrail derives the expected reference doc path for that page
Then it produces exactly one deterministic reference doc path under
  docs/reference/frontend/ for that dynamic route
And the dynamic segment marker [id] is normalized consistently so the same
  route always maps to the same doc path on every commit
```
